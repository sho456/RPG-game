# 技・術の演出（アストラル・ブレイカー）

根拠：ユーザー提供のロマサガRS の録画 2 本（剣の連続技・水の術と召喚。60fps）の実測 → `references/video-2026-11.md`。
効果音の作り方 → `references/sfx-recipes.md`。**動画・音・絵柄は使わない。取り入れるのは時間・構造・色の組み立てだけ。**
どの技も最後に 7 章の「応用と進化」を通し、参考と同じ見た目にならないようにする。

## 0. どこを直すか（この作品のコード）

| 段 | コード | ほかのスキル |
|---|---|---|
| 吹き出し・暗転・明け・数字・撃破 | `js/battle/flow.js`（`BFLOW`）・`js/ui/battle-pop.js`（`BPOP`）・`js/ver19.js dissolve` | rs-battle-flow（`docs/BATTLE-FLOW.md`） |
| 技ごとの体の動き・溜め・放出・着弾 | 台帳 `js/battle/data/fx-heroes-<id>.js` の `BXS.def(技,{pre,strike,impact,after})`・部品 `BXP`・体 `BXR` | rpg-hero-motion |
| エフェクトの絵 | `BXP` の部品・pixelfx（`tools/pixelfx`）で作ってシート化 | pixelfx |
| 効果音 | `js/engine.js` の `tone()`・`SFX`、台帳の `['sfx','名前']`（`js/battle/seq.js`） | `references/sfx-recipes.md` |
| ポーズのコマ（構え・振り・詠唱・発動） | `assets_src/pixel-art/celes-48`・`celes-hd`・`tools/spx_import.py` | rpg-hero-motion |

## 1. 時間割（6 段。速度 ×1。数字は実測）

| 段 | 剣の技（A） | 術（B） | 決まり |
|---|---|---|---|
| ① 予告 | 吹き出し 0〜0.58 | 0〜0.45 | 技名を読ませる。吹き出しの間はまだ暗くしない |
| ② 暗転 | 0.58〜0.75（明るさ 41%） | 0.30〜0.50（64%） | **入りは 0.17〜0.2 秒で速く**。剣は暗く、術は浅めに（術は自分の光で明るくなるので） |
| ③ 溜め | 振りかぶりの止め 130ms | 足元の渦 0.85 秒・術者が跳ぶ | 何が来るかを見せる。術は**敵の足元に予兆**（渦・陣）を先に置く |
| ④ 放出 | 三日月の残像 70ms → 着弾まで 0.37 秒 | 背景を真っ黒＋白い球 0.08 秒 → 弾ける | 放出の直前に**いちばん暗く・いちばん静か**にしてから一気に光らせる |
| ⑤ 着弾・持続 | 1 体ごとに約 0.62 秒の周期 | 柱と召喚 1.1 秒 | 着弾の形：白い芯 → 放射の線 → 輪 → 漂う粒。**広がりは速く（4〜6 コマ）、消えるのは遅く（10〜20 コマ）** |
| ⑥ 結果と明け | 明け 3.00〜3.45（0.45 秒） | 術者が戻る → 明け → 色に染まる → 数字 → 崩れる | **明けは入りより 2〜3 倍長く**。数字・Weak・崩れは明けたあと（rs-battle-flow） |

## 2. 剣の振り（体の動き。rpg-hero-motion の台帳に写す）

| コマ（60fps） | 形 | 台帳での目安 |
|---|---|---|
| 0〜4 | 剣を前下に低く構える・足元に砂ぼこり | `pre` の 1 段目 |
| 4〜8 | 剣を真上へ | `pre` の 2 段目 |
| 8〜16 | **背中側に水平に構えて止める**（刃先に白い点） | `['stop',130]` |
| 16〜20 | **白い三日月の残像**で頭上から前下へ | `strike`（`'in'` の ease・70ms） |
| 20〜 | 低い振り抜きのまま止める・足元から光の柱と輪 | `after` で 200ms 止め |
| 振り下ろしの 0.37 秒後 | 敵に着弾（飛ぶ斬撃なら移動に 0.3〜0.4 秒） | `impact` |

- 連続技は**同じ周期をくり返す**（約 0.62 秒）。単調にしないよう 7 章で 1 撃ごとに角度・色・残像の向きを変える。
- 主人公が動かない技でも、足元の柱・砂ぼこり・刃先のきらめきで「力が出た場所」を見せる。

## 3. 術の段取り

1. 詠唱：術者の周りに属性の輪（詠唱のポーズ：目を閉じる）。
2. 予兆：**敵の足元に地面に沿った楕円**（遠近に合わせて横長。敵の幅の 2〜2.5 倍）。中央に白い光。
3. 発動：術者が跳ぶ（発動のポーズ）。予兆が縮む。
4. 注目：背景を真っ黒にして、敵の位置に白い球（0.05〜0.1 秒）。
5. 放出：星形の閃光 → 本体（柱・落下・爆発）。**召喚は本体に巻き付いて昇る／降りる**。地面に波紋の輪を 3〜4 重。粒（泡・火の粉）は上へ。
6. ほどけ：本体を粒に崩して消す → 背景が戻る → 術者が元の位置へ。
7. 結果：敵が術の色に染まる → Weak → 数字（右の桁から数え上がる）→ 倒したら赤 → 市松のモザイクで 0.25 秒で消える。回復・BP+ は味方に緑の光。

## 4. エフェクトの色と形

- **主の色 1 ＋ 補う色 1 ＋ 白の芯**（参考：剣＝黄＋緑＋白、水＝青＋水色＋白）。補う色は主の色の隣の色相（±60°）。
- 大きな演出（爆発・柱・渦）は**高解像度の光**（加算合成・ぼかし・放射の線）。キャラに付く小さな演出（刃のきらめき・剣の残像・足元の柱）は輪郭のはっきりした形。
  キャラの絵に描き込むときは輪郭なし・同じ色相の 4 段・1〜10 ドットの粒。
- 被弾の色：物理の着弾の瞬間は**白い影 1〜2 コマ**、術の命中は**術の色**、撃破は**赤 → 市松のモザイク**。
- 画面の揺れ・ヒットストップは着弾の瞬間だけ（rpg-hero-motion の `shake`・`['stop',60〜120]`）。

## 5. 効果音（`references/sfx-recipes.md` にコード）

- **層**：技の間ずっと鳴るノイズ（剣＝風、水＝水流で音程が揺れる）。終わりは 0.3〜0.5 秒で消す。
- **打（高い）**：着弾ごとに金属音 3 連打 4.0k → **7.5k（閃光と同じコマ）** → 4.0kHz、0.12 秒間隔。
- **打（低い）**：着弾に「ドン」（250Hz 以下・0.14 秒）。大きな術は上から下へ落ちるノイズを重ねる。
- **合図**：結果・BP+ は下がっていく鈴（8.3k → 5.7kHz・4 音・0.12 秒間隔）。
- 今の `SFX` は発振器だけなので、レシピの `swoosh`（ノイズ）・`ring`・`thump`・`chime` を `js/engine.js` の `SFX` の近くに足して使う。

## 6. 背景

- 背景は描き込んだ絵（ドット絵でなくてよい）。床は奥へすぼまる遠近、光は左上からの帯。
- **キャラより暗く、彩度を低く**（キャラのドット絵が浮く）。暖色の茶か暗い青緑が基準。
- 暗転は背景だけを暗くし、キャラとエフェクトは暗くしない。放出の直前だけ背景を真っ黒に。

## 7. 応用と進化（参考を写さないための決まり。必ず通す）

参考から取るのは**骨組み（時間割・順番・強弱の付け方）**だけ。見た目は次の軸を最低 2 つ変える：
| 軸 | 変え方の例 |
|---|---|
| 形の道筋 | 地をはう斬撃 → 空を弧で飛ぶ・地面から突き上がる・敵の背後から戻る |
| 色の組み | 主の色と補う色を入れ替える・キャラの差し色を補う色に使う |
| リズム | 等間隔の連撃 → だんだん速く・最後だけ溜めて重く・2 撃ずつ組にする |
| 本体のかたち | 柱 → 槍の雨・花が開く・星座の線で囲む |
| 終わり方 | 粒が漂う → 粒が術者へ戻る・星になって昇る |

**この作品らしさ（星）を必ず 1 つ入れる**：星形の閃光・星座の線で結ぶ・流れ星の尾・星の粒（4 方向の十字）・星臨の金色。
キャラの性格も乗せる（豪快なキャラは溜めを長く・残像を太く、素早いキャラは周期を 0.45 秒に縮める、など）。

## 8. 作る順番

1. 参考の録画があれば分ける：`python3 .claude/skills/rs-battle-fx/scripts/vref.py <動画> <scratchpad>/v --crop x,y,w,h`
   → `sheet.png`（流れ）・`timeline.txt`（暗転・閃光の時刻）・`spec.png`／`audio.txt`（音）。キャラの振りは `--zoom x,y,w,h --from n --to n`。
   注意：明るい本体（水柱など）が出ている間は「背景が戻った」と誤って拾うことがある。`sheet.png` で必ず目で確かめる。
2. 1 章の表に、作る技の 6 段の時間を書く → 7 章で変える軸を 2 つ以上と星の要素を決める。
3. 体の動き（2・3 章）を rpg-hero-motion の台帳に、エフェクトを BXP／pixelfx で、効果音を `SFX` に。
4. 確かめる：`node tools/motion_preview.js <id> <技> <出力>`・`node tools/battle_demo.js`（録画）→ `python3 tools/frame_grid.py` でコマの一覧。
   1 章の時間（暗転の入り 0.2 秒・明け 0.45 秒・着弾の広がり 4〜6 コマ）に合っているか、`vref.py` を自分の録画にもかけて比べる。
5. `node tools/smoke.js --quick --fx`。

## 9. 派手さの決まり（試作の評価 50 点 → 第 2 版で足したもの。試作のリオ版は削除済み、セレス版は `assets_src/pixel-art/celes-48/demo/celes_fx.py`）

- 光は 3 層（地面・体の後ろ・前）＋にじみ 2 段（小 6px・大 26px）。スクリーン合成で白に飽和させない
- 命中で：白飛び（画面全体 0.07〜0.14 秒）・ヒットストップ（小 3 コマ・大 6〜8 コマ、60fps）・画面の揺れ（減衰）・敵が後ろへ飛ばされて戻る（14〜50px）
- 動きで：踏み込み・跳躍に残像（金の影 3 つ）と集中線、着地に砂ぼこり
- 斬撃：三日月（太さ 30〜40）＋画面を横切る白い筋。とどめは縦の光の柱で両断
- 粒：火花（速い・線・重力）と燠（遅い・四角・昇る）。1 回の命中で 100 前後、奥義は 300
- 奥義は背景ごと変える（夜空など）・大きな形（星座の剣）を組み上げてから放つ・最後に余韻を 1 つ残す
