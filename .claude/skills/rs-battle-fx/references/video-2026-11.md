## A. 剣の連続技（地をはう斬撃・敵 3 体へ順に・4.1 秒）

| 時刻 | 出来事 |
|---|---|
| 0.00〜0.58 | 技名の吹き出し（術者の左） |
| 0.58〜0.75 | 暗転：背景の明るさ 100% → 41%（10 コマ） |
| 1 周期 約 0.62 秒（× 敵の数） | 下の「振りの 1 周期」 |
| 3.00〜3.45 | 暗転が明ける（27 コマ。入りより長い） |
| 3.4〜3.8 | 倒した敵が赤く染まって崩れる |

振りの 1 周期（主人公はその場を動かない。コマ番号は 60fps）：
| コマ | 時間 | 形 |
|---|---|---|
| 0〜4 | 70ms | 剣を前下に構えて低く。足元に砂ぼこり |
| 4〜8 | 70ms | 剣を真上へ（溜めの入り） |
| 8〜16 | **130ms 止め** | 剣を背中側に水平に構える。刃先に白い光の点（きらめき） |
| 16〜20 | **70ms** | **白い三日月の残像**で頭の上から前下へ振り下ろす |
| 20〜22 | — | 低い振り抜き（前かがみ）。以降この形のまま |
| 22〜34 | 200ms | 足元から光の柱と地面の輪（放つ合図） |
| 振り下ろしの約 0.37 秒後 | — | 敵に着弾：白い芯 → 黄の放射の線 → 緑の輪が広がる（約 15 コマ）→ 緑の光の粒が漂う |
| 着弾と同時 | — | 敵が白い影に一瞬だけ染まる（被弾の閃光）・Critical と数字 |

効果音（スペクトログラム）：
- 技の間（0.4〜3.5 秒）ずっと、広い帯域の風の層（ノイズ）。終わりの 0.5 秒で消える。
- 着弾ごとに **金属音が 3 連打**：4.0kHz → 7.5kHz → 4.0kHz、0.12 秒間隔（真ん中の 7.5kHz が着弾の閃光と同じコマ）。
- 着弾ごとに低い「ドン」（〜250Hz の短い縦の筋）。

## B. 水の術（渦 → 水柱 → 召喚獣・敵 1 体・4.8 秒）

| 時刻 | 出来事 |
|---|---|
| 0.00〜0.45 | 技名の吹き出し |
| 0.30〜0.50 | 暗転：100% → 64% |
| 0.48 | 術者の周りに水の輪が立つ（詠唱の合図） |
| 0.55〜1.40 | 敵の足元に**地面に沿った楕円の渦**（敵の幅の約 2.5 倍）。中央に白い光。画面の上を青い流れが横切る |
| 1.30〜1.50 | 術者が上へ跳ぶ（発動）。渦は輪に縮む |
| 1.55〜1.63 | **背景を真っ黒に**して、敵の位置に白い球（ため・注目） |
| 1.63〜1.72 | 球が弾ける：4 方向の星形の閃光＋上から水柱が落ちる |
| 1.85〜2.95 | 水柱が続き、**水の竜が柱を巻いて昇る**。地面に波紋の輪 3〜4 重・泡の粒が上へ |
| 2.82〜3.15 | 術者が元の位置に降りる。水柱が泡になってほどけ、背景が戻る |

| 3.25〜3.65 | 術者に緑の光と「BP+」（効果の回復） |

効果音：
- 0.3〜1.0 秒：水流のノイズに、上下に揺れる音程の筋（渦）。渦の間、4.3〜4.6kHz の短い音が 0.13 秒ごと（水しぶきのきらめき）。
- 1.78 秒：水柱の着弾。低音の縦の筋（〜900Hz が重心、低域 78%）＋ 7.9kHz の 1 打。
- 3.28〜3.80 秒：**下がっていく鈴の音** 8.3k → 6.5k → 6.1k → 5.7kHz（0.12 秒間隔。結果・BP+ の合図）。

## C. 背景（2 本）

- 背景はドット絵ではなく**描き込まれた高解像度の絵**（石の床・円い手すりの広間／暗い石の地下）。床は奥へすぼまる遠近。
- キャラ（ドット絵）は背景より**明るく彩度が高い**。背景は彩度を落とした暖色の茶（A）か暗い青緑（B）。
- 光：A は左上からの光の帯が床に差し込む。B は全体が暗く、中央の床だけ少し明るい。
- 味方は右に縦 1 列（5 人）、敵は左。大きい敵は味方の約 3 倍の高さ。

## D. エフェクトの描き方（2 本に共通）

- 画面全体の大きな演出は**高解像度の光（加算合成・ぼかし・放射の線）**。キャラに付く小さな演出（足元の柱・刃のきらめき・剣の残像）は輪郭のはっきりした形。
- 1 つの属性で **主の色 1 ＋ 補う色 1 ＋ 白の芯**（A：黄＋緑＋白／B：青＋水色＋白）。
- 形の順番：**芯（白）→ 放射（主の色の線）→ 輪（補う色）→ 漂う粒（補う色）**。広がりは速く、消えるのは遅い。
- 敵の被弾の色：着弾の瞬間は白、術の命中では術の色、倒したら赤 → 市松のモザイクで消える。
