# RS 風ドット絵（アストラル・ブレイカー）

参考：ロマサガRS の戦闘キャラ（ユーザー提供の参考シート・方眼の絵）と、ロマサガ風ドット絵の解説
（[ドットアートプレイ](https://dotartplay.com/romasaga-dot)。自動では読めないので、検索で確かめた要点だけ）。
学習記録：`.claude/skills/pixel-art-studio/references/learned/006-rs-battle-chibi.md`（シート全体）・`007-rs-pixel-anatomy.md`（1 ドット単位の体の作り）。
**取り入れるのは大きさ・描き方・ポーズの種類だけ。キャラ・衣装・ポーズそのものは真似しない。**

## 1. 大きさ

| 項目 | 決まり |
|---|---|
| キャンバス | 立ちは **32×32 以内**。素材のマスは 48×48（足元 y=45、体の前端 x≈14）で、武器・蹴り・倒れがはみ出しても足元は動かさない |
| 身長 | 男 **30〜31**・女 **27〜29**・大柄 32（角・帽子を除く）。立ちの幅は **14〜16**（武器を除く） |
| 頭 | 身長の**約半分**（男：髪の上端から顎まで 15 行・幅 13〜14）。髪の先は 1 ドットの棘で輪郭から飛び出す |
| 胴 | 8 行・幅 10（輪郭込み）。脚は 1 本 2 ドット＋間に輪郭。足は前（左）を向く |
| 向き | 戦闘は**左向きの 3/4**。横向きでも**両目を描く** |

## 2. 顔（いちばん大事）

```
行  …  o  o  ．  o  o    ← まぶた：輪郭色 2 ドット × 2（奥の目・手前の目）
行  …  o  濃  肌  濃  白   ← 目の上の段：瞳の濃い色、手前の目の右に白目 1 ドット
行  …  o  明  肌  明  白   ← 目の下の段：瞳の明るい色
```
- 目は **1 ドット幅 × 2 ドット**（上が濃い・下が明るい）。奥の目は顔の前端、肌 1 ドットあけて手前の目、その右に白目。
- 鼻・口は描かない。顎は肌 3〜4 ドット。前髪が 2〜3 本、額に垂れて、間から肌がのぞく。
- 前髪の下とうなじに髪のいちばん暗い色。

## 3. 色と光

- 輪郭は **1 色**（`#1c1a26`、参考は `#202020`）。シルエット・部品の境目・**服のしわ**にも引く（全画素の 3〜4 割が輪郭になるのが目安）。
- 予算：輪郭 1・肌 3・髪 3〜5・服は 1 着 **2 色**・金属 3・靴 2・差し色（襟・マフラー）1〜2。合計 20〜26 色。ディザは使わない。
- **手前ほど明るく、奥ほど暗く**（奥の腕・脚・髪の後ろは暗い段）。光は左上から。
- オーラ・光はドットに描かない（演出の層 js/battle が描く）。

## 4. ポーズ（21 コマ）

| 区分 | コマ | 戦闘のポーズ名（`anims` のキー） |
|---|---|---|
| 待機 | 待機 1〜2（呼吸：胴と頭を 1 ドット下げる） | `stance` |
| 構え | 構え（引く・溜める。体を 2〜3 ドット後ろへ） | `ready` |
| 攻撃 | 振りかぶり・斬り（スミア 1 コマ）・振り抜き。体術は蹴り（脚を水平に、幅 25 前後） | `lunge` ／ `attack@n` |
| 詠唱 | 詠唱 1〜2 | `cast` |
| 走り | 走り 1〜3 | `dash` |
| 被弾 | 被弾（頭と肩を 3〜4 ドット後ろへ） | `hit` |
| 瀕死 | 瀕死（片膝・武器を地面に） | `weak` |
| 戦闘不能 | 倒れ（高さ 8〜10） | `down` |
| 勝利 | 勝利 | `win` |
| 図鑑・編成 | 正面 1〜3・背面 1〜3・横歩き 1〜3 | `front` `back` `walk_a` `walk_b` |

攻撃の時間の目安：構え 120〜160ms → 斬り 50〜60ms → 振り抜き 200ms（止め）→ 待機へ。

## 5. 作り方

1. **地図で 1 ドットずつ置く**（見本：`assets_src/pixel-art/rio-rs2/build.py`）。文字＝色、`.`＝透明、`o`＝輪郭。
   参考と同じ手順：**輪郭 → 塗り → ハイライトと影 → 細部**。武器など地図の外にはみ出すものは「追加の点」に書くと輪郭が自動で付く。
   ```bash
   python3 assets_src/pixel-art/<id>-rs/build.py        # out/<ポーズ>.png（48×48）・preview.png と、規格の検査結果
   python3 .claude/skills/rs-style-sprite/scripts/rs_check.py out/待機.png
   ```
2. **参考と並べて見る**：同じ倍率で並べた画像を作って目で比べる（高さ・頭の大きさ・目・輪郭の密度）。
3. **ポーズを増やす**：待機の地図を「頭・胴・奥の腕・手前の腕・脚」に分け、ポーズごとにずらし・差し替える。
   頭の地図は全ポーズ共通（被弾・倒れは向きだけ変える）。大きく形が変わるポーズ（蹴り・倒れ）は 1 枚まるごと描く。
   関節の座標から部品を自動で描く方式（`assets_src/pixel-art/rio-rs/build.py`、第 1 版）は、**ポーズの当たりを付ける下書き**にだけ使う。
4. **参考の方眼画像が届いたら**：`python3 .claude/skills/rs-style-sprite/scripts/grid2png.py 方眼.png out.png` で実寸に戻し、
   `rs_check.py` で数を取り、pixel-art-studio の学習記録に追記する（画像そのものはリポジトリに入れない）。
5. **ゲームへ**：`python3 tools/spx_import.py init <id>` → コマを `assets_src/chars/<id>/anim/<ポーズ>/frame_000.png…` に置く →
   `character.json` の `anims` に登録 → `python3 tools/spx_import.py build <id>`（`docs/PIPELINE.md` 3-3）。
   **表示は整数倍**（1 ドット＝端末の画素の整数倍）。動かし方と演出は `rpg-hero-motion`。

## 6. 見るべき失敗

| 見えたもの | 直し方 |
|---|---|
| ずんぐり・幅が 18 以上 | 胴を幅 10 に、脚を 2 ドットずつに。肩当て・マントで横に広げない |
| 目が大きい・目が 1 つに見える | 目は 1 ドット幅 × 2。間に肌 1 ドット、上にまぶた 2 ドット、手前の目に白目 |
| のっぺりして見える | 服のしわを輪郭色で 1〜2 本、手前を明るく奥を暗く |
| 顔が髪に埋もれる | 前髪の本数を減らし、顎の肌を 3〜4 ドット見せる |
| 実寸で何をしているか分からない | 構え・斬り・被弾はシルエットを大きく変える（体ごと 2〜6 ドット動かす） |
