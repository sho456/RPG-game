# RS 風ドット絵（アストラル・ブレイカー）

参考：ロマサガRS の戦闘キャラ（ユーザー提供の参考シート。学習記録は
`.claude/skills/pixel-art-studio/references/learned/006-rs-battle-chibi.md`）。
**取り入れるのは大きさ・描き方・ポーズの種類だけ。キャラ・衣装・ポーズそのものは真似しない。**

## 1. 規格

| 項目 | 決まり |
|---|---|
| マス | 1 コマ 48×48（攻撃などで武器がはみ出すコマも同じマス。足元の位置を全コマでそろえる） |
| 足元 | y = 45（下から 3 ドット空ける）。体の中心は x = 24 前後 |
| 身長 | 約 30 ドット（帽子・髪の逆立ちを入れて 34 まで）。頭は身長の 4 割（高さ 12〜13・幅 13〜14） |
| 向き | 戦闘の横向きは**左向きの 3/4**（敵の側）。素材は左向きで描き、`face:'L'` で登録する |
| 輪郭 | 1 ドットの濃い色（`#1c1a26`、真っ黒にしない）。シルエットの外側だけでなく、**重なる部品の境目にも**引く |
| 光 | 左上から。髪の左上に明るい塊を 1 つ、服と鎧は右・下が暗い |
| 色 | 1 キャラ 22 色前後：輪郭 1・髪 4・肌 3・目 3・服 3・差し色 2・鎧（金属）3・小物 2〜3。ディザは使わない |
| 目 | 高さ 2（上が濃い色・下が瞳の色）＋ 1 ドットの光。奥の目は顔の左端 |
| 光り物 | オーラ・光は素材に描かない（演出の層 js/battle が描く） |

## 2. ポーズ（21 コマが基本形）

| 区分 | コマ | 戦闘のポーズ名（`anims` のキー） |
|---|---|---|
| 待機 | 待機 1〜2（呼吸：胴と頭を 1 ドット下げる） | `stance` |
| 構え | 構え（引く・溜める） | `ready` |
| 攻撃 | 斬り下ろし（スミア 1 コマ）・振り抜き | `lunge` ／ `attack@n` |
| 詠唱 | 詠唱 1〜2（両手を前・胸の前に光の位置） | `cast` |
| 走り | 走り 1〜3（前傾・大きな歩幅） | `dash` |
| 被弾 | 被弾（頭と肩が後ろへ 3〜4 ドット） | `hit` |
| 瀕死 | 瀕死（片膝・武器を地面に） | `weak` |
| 戦闘不能 | 倒れ（マスの下 20 ドット） | `down` |
| 勝利 | 勝利（武器を掲げる） | `win` |
| 図鑑・編成 | 正面 1〜3・背面 1〜3・横歩き 1〜3 | `front` `back` `walk_a` `walk_b` |

攻撃の時間の目安：構え 120〜160ms → 斬り下ろし 50〜60ms → 振り抜き 200ms（止め）→ 待機へ。

## 3. 作り方（見本：`assets_src/pixel-art/rio-rs/build.py`）

1. **頭の地図を 1 ドットずつ描く**（`HEAD`：文字＝色。髪 a〜d・肌 e〜g・目 j i w）。顔はキャラの印象のすべてなので、ここだけは手で置く。
2. **体は関節の表で描く**：`POSES` に `head neck hip far_leg near_leg far_arm near_arm sword` の座標を書くと、
   部品（脚・腕・コート・マフラー・肩当て・剣）が「塗る → 左上からの 3 段の陰影 → 外側に輪郭 → 奥から手前へ重ねる」で描かれる。
   新しいポーズは表に 1 行足すだけ。武器を頭の後ろに担ぐコマは `sword_behind:1`。
3. **実行して目で見る**：`python3 assets_src/pixel-art/<id>-rs/build.py` → `out/preview.png`・`out/compare.png`（参考と同じ倍率で並べる）・GIF。
   身長と幅は数値でも確かめる（stats と bbox）。
4. **直す**：いちばん悪い所を 1 つずつ。よくある失敗：
   | 見えたもの | 直し方 |
   |---|---|
   | 参考より大きい・ずんぐり | ポーズの縮尺 `K`、頭の地図の幅、手足の太さ（脚 3.4・腕 3.2） |
   | 顔が隠れる | 肩当て・マフラーを小さく、手前の腕を頭より奥の層に |
   | 攻撃に見えない | 構えで 2〜3 ドット後ろへ・斬り下ろしで前足を大きく前へ、スミアを 1 コマ |
   | 黒くつぶれて腕が読めない | 腕の明るい段を 1 つ上げる、腕と胴の境目の輪郭を残す |
5. **ゲームへ**：`python3 tools/spx_import.py init <id>` → `out/` のコマを `assets_src/chars/<id>/anim/<ポーズ>/frame_000.png…` に
   書き出し → `character.json` の `anims` に登録（`docs/PIPELINE.md` 3-3）→ `python3 tools/spx_import.py build <id>`。
   **表示は整数倍**（ドットが崩れないように、30 ドットの絵を 1 ドット＝2〜3 CSS px で描く）。動かし方と演出は `rpg-hero-motion`。

## 4. 品質の基準

- 実寸（1 倍）で、誰か・何をしているかが分かる。
- 全コマで足元・身長・色がそろう（コマ送りで跳ねない）。
- 攻撃は「引く → 一瞬で前 → 止め」の 3 段が読める。
- 1 キャラのパレットは全コマ共通。新しい色を足すときは全コマで使う。
