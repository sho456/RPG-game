# RS 風ドット絵（アストラル・ブレイカー）第 3 版

根拠：ユーザー提供の RS 実機スプライト 19 枚の実測（`references/measure-v2.md`：正面 1・立ち 2・構え 4・瀕死 2・気絶 2／`references/design-v3.md`：正面 2・詠唱 1・発動 2・コマンド選択 3 と、キャラデザイン分析）。
第 1 版の根拠（方眼の絵・シート）：pixel-art-studio の学習記録 `006-rs-battle-chibi.md`・`007-rs-pixel-anatomy.md`・`008-rs-pose-measure.md`（第 2 版）・`009-rs-character-design.md`（第 3 版）。
**取り入れるのは大きさ・描き方・ポーズの形と数値だけ。キャラ・衣装・配色・ポーズそのものは真似しない。参考画像はリポジトリに入れない。**

第 1 版からの主な変更（実機と食い違っていた所）：
| 項目 | 第 1 版 | 第 2 版（実測） |
|---|---|---|
| 内側の線 | 部品の境目・服のしわもすべて輪郭色 | **外周だけ純黒**。内側は素材のいちばん暗い段。黒は目・重なり・前髪の下など要所だけ |
| 服 | 1 着 2 色 | **3〜6 段**で色相をずらす |
| 目 | 1 ドット幅 × 2（濃・明）＋まぶた | **縦 3 段**（まぶた黒・瞳の上段黒・虹彩）。白目は縦 2 |
| 輪郭の色 | #1c1a26 | **#000000** |
| ハイライト | 決まりなし | 白に近い色を 1〜9%（髪の天使の輪・金属・白目） |
| ポーズ | 種類だけ | 高さ比・幅・地面の高さ・重心まで数値で。第 3 版で詠唱・発動 |
| デザイン | 決まりなし | 第 3 版：配色の型・髪型・衣装の組み立て（7 章） |

## 1. 大きさと置き場所

| 項目 | 決まり |
|---|---|
| マス | 素材は 48×48。足元 y=45・体の前端 x≈14（`rsmap.py`）。参考の実機は足元 y=38・体の中心 x≈24 |
| 立ちの高さ | 標準 **30**（28〜31。小柄 27・大柄 32。角・帽子を除く） |
| 立ちの幅 | **15〜17**（武器を除く。髪の広い正面は 18） |
| 頭 | 髪のてっぺん〜顎で **14 行＝高さの 45〜47%**。目の段は上から 11〜12 行目、顎は目の 2〜3 行下 |
| 重心 | 立ちは頭が足より **2.5〜3 ドット敵側（左）**。後ろ髪・裾・マントが後ろへ流れて釣り合う |
| 向き | 戦闘は **左向きの 3/4**（正面は図鑑・編成用）。横向きでも両目を描く |

## 2. 顔（いちばん大事）

```
      奥の目   手前の目
y+0   o   肌   o   o      ← まぶた：奥の目に 1、手前の目＋白目に 2（#000000）
y+1   ■   肌   ■   白     ← 瞳の上段：#000000（まぶたとつながり、太いまつげに見える）
y+2   色   肌   色  白     ← 虹彩：その子の目の色（彩度の高い 1 段）。白目は縦 2
y+3   影   肌   肌  肌     ← 目の下：奥側の頬は肌の 3 段目
```
- 目と目の間は **肌 1 ドット**（正面は 2 ドット。白目は両目の外側に 1、瞳の上段は虹彩のいちばん暗い色）。
- 鼻・口は描かない。顎は肌 3〜4 ドット。前髪 2〜3 本が額に垂れ、間から肌がのぞく。前髪の下は黒 1 行。
- 肌は **4 段**（例：#fee5d7 → #ffbcaa → #e49478 → #c96941。陰ほど赤く）。顔の奥側・顎の下・髪の下に 2〜3 段目。

## 3. 線と色

- **外周は #000000 の 1 ドット線で 100%**（検査で 0.92 以上）。エフェクト（精霊・オーラ・光）は輪郭なしで別の層（js/battle）。
- **内側の黒は全体の 7〜13%** だけ：目とまぶた・腕と胴の重なり・前髪の下・脚の間・ベルトや襟の切れ目。
  それ以外の部品の境目・しわは **その素材のいちばん暗い段**で引く（青い髪の中の線は暗い青）。黒の総量は 24〜34%。
- 段数：**髪 5**（最後は白か白に近い色。てっぺんの丸みに沿って 2〜3 ドットの「天使の輪」）・**肌 4**・**服 3〜6**・金属 3〜4・差し色 1〜2。
  合計 **17〜22 色**（素朴な服）／**28〜36 色**（装飾の多い服）。ディザは使わない。
- **色相をずらす**：陰は赤・青の側へ、光は黄・水色の側へ。中間の段ほど彩度を高く。**灰色の陰は使わない**（鎧・刃だけ。全体の 15% まで）。
  実測の段の例は `references/measure-v2.md` 3 章（髪 青・金、服 緑、肌）。
- **白に近い色を 0.5〜9%**：髪の天使の輪・金属の光・白目・服の縁取り。
- **術・技のエフェクト**（キャラの絵に描き込むとき）：黒の輪郭を使わず、**同じ色相の 4 段**（暗・中・明・白）。外周は暗の段で閉じる。
  体から離れた 1〜10 ドットの粒を 6〜10 ドットの範囲に散らす。ふだんは別の層（js/battle）で描く。
- 光は**前上（左上）**から。手前の腕・脚・髪の前側を明るく、奥と後ろ髪・うなじを暗く。

## 4. ポーズ（数値は立ちの高さ Hs に対する比。`rs_check.py --pose` が見る）

| ポーズ | 高さ | 幅 | 地面（足元からの上がり） | 形 |
|---|---|---|---|---|
| 正面 `front` | 28〜31 | 15〜19（多くは 16） | 0 | 左右対称（鏡の重なり 0.75 以上、実機 0.98〜1.00）。腕は体の横。目の間は肌 2 |
| 立ち `stand` | 28〜31 | 15〜17 | 0 | 足をそろえ地面 1 か所。頭は足より 2.5〜3 前 |
| 構え `ready`（待機） | **0.93〜0.97 Hs**（−1〜−2） | **24〜25**（20〜26） | 0 | 膝を曲げ足を開く。前の腕・武器が顔より 3〜6 前。髪・リボン・帯が後ろへ 3〜6 流れる。頭は足より 0〜6 前 |
| コマンド選択 `select` | 0.97〜1.0 Hs（29〜30） | **22〜23** | 0（つま先 1 点） | 前へ跳び出す形：後ろの脚を膝から曲げて上げ、もう片方を下ろしてつま先だけで地面に触れる（前の脚を水平に蹴り出す形も）。前の腕を前へ。頭は足より 0〜4 前 |
| 詠唱 `cast` | 1.0 Hs（杖込み 1.07） | 16〜18（杖込み 27） | 0 | 体はまっすぐ、頭を 1 下げ、**目を閉じる＝横 2 の黒線**。杖は体の前で縦に、頭の上 2〜4・足の下 1〜2 まで |
| 発動 `act` | 1.0 Hs | 24（術のエフェクト込み 35） | 0（片足が浮く） | 体を敵へ開き、**前の腕を肩の高さで伸ばし手のひらを見せる**（顔より 6〜8 前）。後ろの腕は引く。**片足を上げて跳ぶ**。髪・帯は上と後ろへはね上がる |
| 瀕死 `weak` | **0.80〜0.87 Hs**（24〜26） | 20〜24 | **1〜2 上** | 膝をつく・座り込む。頭を 3〜4 下げて前へ傾ける。手か武器を地面に。髪が前に垂れる |
| 気絶 `down` | **0.47〜0.50 Hs**（14〜15） | **Hs+2**（32） | **4 上** | 横に倒れる。頭は片方の端。顔は隠すか閉じた目。肩と腰に 1〜2 の盛り上がり |

戦闘のポーズ名（`anims` のキー）との対応と、残りのコマ：
| 区分 | コマ | キー |
|---|---|---|
| 待機 | 構え 1〜2（呼吸：胴と頭を 1 下げる。足は動かさない） | `stance` |
| 溜め | 構えから体を 2〜3 後ろへ | `ready` |
| 攻撃 | 振りかぶり・斬り（スミア 1 コマ）・振り抜き。体術の蹴りは幅 25 前後 | `lunge` ／ `attack@n` |
| 詠唱・発動 | 上の表（詠唱 1〜2 コマ＝杖を構える→目を閉じる、発動 1〜2 コマ＝腕を伸ばす→跳ぶ） | `cast` ／ `act`（`act` はゲームにまだ無いキー。足すときは rpg-hero-motion の `BXR.POSE` に） |
| 走り・被弾 | 走り 1〜3・被弾（頭と肩を 3〜4 後ろへ） | `dash` `hit` |
| 瀕死・気絶・勝利 | 上の表 | `weak` `down` `win` |
| コマンド選択 | 選ばれている味方 1 コマ（構えから 1 歩前へ跳ぶ） | `select`（ゲームにまだ無いキー） |
| 図鑑・編成 | 正面 1〜3・背面 1〜3・横歩き 1〜3 | `front` `back` `walk_a` `walk_b` |

攻撃の時間の目安：構え 120〜160ms → 斬り 50〜60ms → 振り抜き 200ms（止め）→ 待機へ。

## 5. 作り方

1. **参考があれば実寸に戻して測る**（拡大のスクショ・WebP・JPEG。方眼の線があるなら `grid2png.py`）：
   ```bash
   S=.claude/skills/rs-style-sprite/scripts
   python3 $S/rs_ref.py <scratchpad>/ref a.webp:正面 b.webp:立ち c.webp:構え d.webp:瀕死 e.webp:気絶
   # → 01正面.png…（実寸）・sheet.png・grid.png（8 ドットごとの線）・report.txt（数値）
   ```
   顔は `grid.png` を切り抜いて 1 ドットずつ見る。数値と決まりを pixel-art-studio の学習記録に足す。
2. **地図で 1 ドットずつ置く**（`scripts/rsmap.py`。見本 `assets_src/pixel-art/rio-rs2/build.py`）。文字＝色、`.`＝透明、`o`＝輪郭（`#000000` を渡す）。
   順番：**外周の黒 → 平塗り（中間の段）→ 陰の段・光の段 → 内側の境目（暗い段）→ 要所の黒 → 白のハイライト → 目**。
3. **ポーズを増やす**：立ちの地図を「頭・胴・奥の腕・手前の腕・脚・後ろ髪」に分け、4 章の数値どおりに下げる・開く・傾ける。
   頭の地図は全ポーズ共通（瀕死は 3〜4 下げて前へ 1 傾け、気絶は 90° 回して描き直す）。大きく形の変わる構え・気絶は 1 枚まるごと描いてよい。
4. **検査**（立ちを基準に高さの比を見る）：
   ```bash
   python3 $S/rs_check.py out/立ち.png out/正面.png out/構え.png out/詠唱.png out/発動.png out/瀕死.png out/気絶.png --stand out/立ち.png
   ```
   `notes` が `OK` になるまで直す。`scheme` で配色の型（同系型・対比型・補色型）、`closed` で詠唱の閉じた目も見る。参考の `sheet.png` と同じ倍率で並べて目でも比べる（高さ・頭の大きさ・目・黒の量・色の段）。
5. **新しいキャラはまず設計シート**（7 章）：配色の型・髪の房と動く部品・髪飾り・胴の区切り・靴の色・持ち物を 1 行ずつ決めてから地図に入る。
6. **ゲームへ**：`python3 tools/spx_import.py init <id>` → `assets_src/chars/<id>/anim/<ポーズ>/frame_000.png…` →
   `character.json` の `anims` → `python3 tools/spx_import.py build <id>`（`docs/PIPELINE.md` 3-3）。表示は整数倍。動かし方は `rpg-hero-motion`。

## 7. キャラデザイン（造形・髪型・配色・衣装）

根拠と例：`references/design-v3.md`。**決まりだけを使い、参考のキャラ・衣装・配色は写さない。**

**配色の型を最初に 1 つ選ぶ**（16 枚の内訳：同系型 10・補色型 3・対比型 3）
| 型 | 髪と衣装の色相の差 | 組み立て |
|---|---|---|
| 同系型（いちばん多い） | 30° 以内 | 近い色でまとめ、反対側の色を**差し色 3〜8%**（袖・肩布・腕輪・髪飾り）。明るさの差で頭と体を分ける |
| 補色型 | 120° 以上 | 髪と衣装を離す。衣装の中に髪の色を小さく戻す（襟・靴） |
| 対比型 | 60〜90° | 明るさの差を大きく。金髪＋桃、緑髪＋橙など |
- 暖色（赤・橙・黄）を必ずどこかに入れる（16 枚中 10 枚が暖色が主）。金・黄は白の段まで上げてきらめかせる。
- 暗い服は 1 段目を色の付いた暗色（#1c2b34 くらい）にして黒の輪郭とつぶれないように。

**造形**
- **髪がいちばん大きい色の塊**（頭の部分の 45〜80%）。頭の幅は体の 0.9〜1.4 倍、てっぺんを 1〜3 盛る。
- 髪は 2〜4 ドットの**房**に分け、先を 1 ドットにとがらせて輪郭から出す。房ごとに暗い縁 → 中 → 明るい筋 → 白の点。前髪 3〜4 房。
- **動く部品を最低 1 つ**（ポニーテール・サイドの房・リボン・鉢巻の端・帯・マフラー）。構え・発動で 3〜6 なびかせる。
- **髪飾りを 1 つ**（差し色で 3〜6 ドット、頭頂か奥側）。
- 胴は**横の区切り 3 本**：首元の明るい部品（2〜4）→ 胸の帯・飾り → 腰のベルト（1 行の差し色）。
- 袖は**色の違う袖口・腕輪 1〜2 行**で終える。スカート・袴は裾へ広げ（幅 12〜16）、**裾に 1 行の縁取り**。
- 靴は 2〜3 ドット、**衣装と違う色**（金・橙・緑）。模様（しま・市松）は衣装の 1 か所だけ。
- 杖は身長より長く、先端に 4〜6 の飾り。武器は体の後ろ・斜めに出して身長の枠を越えてよい。

**設計シート**（新しいキャラはこれを埋めてから描く）
```
型：同系型（髪 橙 30° ／衣装 赤 0°・差し色 紫 270°）
段：髪 5・肌 4・衣装 主 4・副 3・差し色 2・金属 3・靴 2 → 23 色
髪：肩までの外はね、前髪 4 房、動く部品＝右のサイドテール、髪飾り＝紫のリボン（頭頂の奥）
胴：金の首飾り → 赤い胸当て → 紫のベルト／袖口：金の腕輪／裾：白の縁取り／靴：金
持ち物：杖（身長＋6、先端は輪）
```

## 8. 応用と進化（参考を写さないための決まり。新しいキャラ・ポーズは必ず通す）

参考の実測から取るのは**規格（大きさ・目・線・色の段・ポーズの数値）と組み立て方**だけ。キャラそのものは毎回この作品のために作る。
1. **参考のどのキャラとも、次の軸のうち 3 つ以上を変える**：髪の形（長さ・房の向き・動く部品の種類）／配色の型と色相／衣装の系統（ドレス・鎧・袴・コート…）／持ち物／シルエット（肩・裾・帽子で外形を変える）。
   描き終えたら参考の `sheet.png` と並べ、「どのキャラに似ているか」を言えたら直す。
2. **この作品らしさを 1 つ入れる**：星・灯（ともしび）のモチーフ（髪飾り・胸の飾り・裾の模様・杖の先）、星臨で光る部分（金の段）。
