案1（48px デフォルメ・`../celes-48`）と案2（HD 100px・`../celes-hd`）を、同じ戦い（同じ敵・同じ技の時刻）に入れて見比べるデモ。

- `preview/td_celes1.mp4`（案1）・`preview/td_celes2.mp4`（案2）・`preview/td_compare.mp4`（上が案1・下が案2）・`preview/*_sheet.jpg`（コマの一覧）
- 作り直し：`python3 tdcore.py 1` / `python3 tdcore.py 2`（`out/` に mp4 とシート）。要所だけ：`python3 tdcore.py 1 peek 4.9 9.2 14.6`

## ファイル（各ファイルは自分の役割だけ。名前と引数の約束は tdcore.py と style0.py の先頭）
| ファイル | 役割 |
|---|---|
| `tdcore.py` | 土台：レーン・敵の行進（助走 6 秒）・ダメージ・スローの陣・ノックバック・撃破とコイン・技の予定（4.2 刻の矢／8.4 クロノスロウ／13.4 終焉の針、間は自動の通常攻撃）・音・書き出し |
| `stage.py` | 夜の時計塔の街道（480×270 で描いて 2 倍）と拠点（星の時計塔と浮かぶ水晶） |
| `enemies.py` | 敵 3 種：時計虫（群れ）・亡霊・歯車の巨像（ボス）。歩き・のけぞり・攻撃 |
| `ui.py` | WAVE・拠点 HP・所持金・技ボタン（チャージの扇・たまると脈打つ・指でタップ）・コインが所持金へ飛ぶ・WAVE CLEAR |
| `style0.py` | 演出の型の見本（仮） |
| `style1.py` | 案1：ドット絵寄りの演出（半分の解像度で描いて 2 倍・2px の格子・色は 4 段）。48px の連続コマで動かす |
| `style2.py` | 案2：なめらかな光の演出。5 枚のポーズからドットを動かして詠唱・反動・跳躍のコマを作る |

## TD 向けにした決まり（RPG 版との違い）
- ゲームを止めない：画面全体の暗転なし。奥義だけ 0.5 秒以内の細い帯のカットインと、着弾直前のごく短い 0.3 倍の遅回し
- 短い：通常攻撃 0.4 秒・刻の矢 約 1 秒・クロノスロウ 0.9 秒（陣は 6 秒残る）・終焉の針 2 秒
- 読める：狙いの印・範囲の楕円・陣の残り時間・遅くなった敵の印。範囲の技の数字は 1 回に 4 体まで。揺れは通常 0〜2px・奥義 8px まで
- まとまり：紫（主）・金（時計と星）・青（宝石）・白（芯）と、時計の刻印・星の閃光・時の欠片
