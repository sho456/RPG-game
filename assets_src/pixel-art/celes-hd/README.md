# セレス HD（ゲーム実装案その2・等身そのまま版）

`celes-48`（48px のデフォルメ版）とは別の案。下絵 5 枚の全体（等身・形・色）はそのままに、
下絵のマス目（1 ドット＝約 22.5px）を 1 ドットに戻して、高さ約 100 ドットのゲーム素材に仕上げたもの。
大きさは 8 方向モデル（`src/model_8dir.gif`、60×104）とそろう。

## 置き場所
- `sprites/celes_hd_{front,side,ready,dying}.png` … 80×104・透過 PNG（足元を下端から 2 ドット上・足元の中心をキャンバス中央に）
- `sprites/celes_hd_faint.png` … 気絶（96×54）
- `sprites/celes_hd_sheet.png` … 5 枚を横に並べたシート・`sprites/palette.npy` 5 枚共通パレット（34 色）
- `preview/celes_hd_preview.png` … 上＝下絵、下＝仕上げ、右下＝8 方向モデル（等倍の 4 倍）
- `preview/celes_hd_mockup.png` … 戦闘の背景に並べた見本
- `src/sketch_*.png` … 下絵を 1 マス＝1 ドットに戻しただけのもの

## 手順
1. `sample.py` 縦横の明るさの変化からマス目（22.53px）と位置を測り、各マスの中央の中央値で 1 ドットに
2. `build.py` 外側の白を透過（閉じた白い隙間も、まわりが輪郭なら透過）→ 5 枚まとめて k-means で減色し、近すぎる色をまとめる
   → 孤立した 1 ドット・輪郭のとげ・JPEG のよごれ・白いにじみを取る → 外側の輪郭の抜けを黒で補う → 足元をそろえる
3. `sheet.py` シートと比較の見本

## 技・術の演出デモ（`demo/`）
`python3 demo/skills.py [tokiya|slow|shuuen|all]` → `demo/out/celes_hd_<技>.mp4`（60fps・1920×1080・音つき）と `_sheet.png`（コマの一覧）。
`all` で 3 本をつないだ `celes_hd_demo.mp4` も作る。要所のコマだけ見るときは `python3 demo/peek.py <技> τ1 τ2 …`。
字体（Kaisei Tokumin）は初回に `demo/out/fonts/` へ取得（git の対象外）。完成の動画は `preview/` に置く。

- `fxcore.py` 土台：背景（夜の時計塔の広場・奥義の夜空）・敵「時喰いの亡霊」（コードで描くドット絵）・光の層の加算とにじみ・
  部品（刻印の時計 `clock`・星の閃光 `star`・着弾 `impact`・粒 `burst`）・文字（吹き出し・金属の数字）・
  時間（ヒットストップとスロー `Timeline`）・効果音の合成（`s_*`・残響つきの `Mixer`）・4 プロセスで書き出し
- `skills.py` 技 3 本（どれも 予告 → 暗転 → 溜め → 放出 → 着弾 → 明け）
  - 刻の矢：宝石のまわりを回る 3 本の「時計の針の矢」→ だんだん速い 3 連射 → 刺さった矢が敵の身の時計の針になって早回し → 真っ黒＋白い球 → 時計ごと砕ける
  - クロノスロウ：地面と敵の背後に大時計 → 杖から光 → 時が遅くなる波（背景が紫の単色・スロー・刻みの音も伸びる）→「カチッ」で針が止まり敵ごとに輪が締まる → 砕けて欠片が降る
  - 終焉の針：カットイン → 夜空 → 昇る → 空の大時計に 12 の星が灯り星座の線で結ばれる → 長針が外れて巨大な針に → 真っ黒の静寂 → 落ちて貫く → 光の柱・9 連撃 → 星の雨 → 敵が崩れる → 降りて決めポーズ
- まとまりの決まり：色の役割は 紫（主）・金（時計と星）・青（杖の宝石＝溜め）・白（芯）の 4 つだけ。どの技も同じ刻印・星の閃光・着弾・時の欠片で組む
