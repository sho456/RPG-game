# セレス 48px（ゲーム実装案その2）

ロマサガRS風（リオ）とは別のスタイル。下絵の全体はそのままに、48×48 のゲーム素材に仕上げたもの。

## 置き場所
- `sprites/celes48_{front,side,ready,cast,dying,faint}.png` … 48×48・透過 PNG（足元を下端にそろえる）。正面・横向き・構え・詠唱・瀕死・気絶
- `sprites/celes48_awake.png` … 星臨（銀河柄の服）。専用パレット `sprites/palette_awake.npy`（42 色）
- `sprites/celes48_sheet.png` … 6 コマを横に並べたシート（288×48）・`sprites/palette.npy` 共通パレット（32 色）
- `sprites/anim/<ポーズ>/frame_000.png …` … 連続モーションのコマ（`motion.py` で作る。全コマ同じキャンバス・足元固定）
  待機 4・詠唱 4・詠唱に入る 2・発動 4・被弾 3・瀕死 4・倒れる 4・気絶 2・回る 5・着地 3・大きく振る 3・正面 2
  星臨：待機 4・詠唱 4・発動 4・振る 3・着地 3・浮遊 4（銀河の髪がなびく。服の星は描き替えない＝チカチカさせない）
- `preview/` … 下絵との比較・連続コマの一覧（`motion_sheet.png`）・実装の予想図（`celes48_mockup.png`）・演出デモの動画（`celes_demo_v5.mp4` 5 本・`celes_ougi.mp4` 奥義・`celes_kokunoya.mp4` 刻の矢）・コマ一覧（`ougi_sheet.png` `kokunoya_sheet.png` `chien_sheet.png`）
- `src/sketch_*.png` … 下絵を元の解像度（36px のマス目 → 1 ドット）に戻したもの
- `out/`（git の対象外）… 作業中の書き出し

## 手順
1. `sample.py` 下絵のマス目（36px）を見つけ、マスの中央の中央値で 1 ドットに戻す（高さ約 53 ドット）
2. `build.py` 背景を外側から透過、4 枚共通のパレット（32 色：k-means＋肌・瞳・涙の色を固定で追加）に減色
3. `shrink.py` 背景の白い隙間を透過、重複の多い行を 5 行抜いて高さ 48 に（顔の行は抜かない）
4. `clean.py` 足元のにじみ（灰色の行・裾の茶色）を取り除き、足元を下端にそろえる
5. `eyes.py` 白目を 1 ドットずつ入れる（正面は外側・横と構えは瞳の後ろに縦・瀕死は半分閉じた目）
6. `sample2.py` → `proc2.py` → `clean2.py` → `eyes2.py` 気絶・詠唱（共通パレットに合わせて減色。気絶は縦横ともほかと同じ縮み率 48/53。下絵がぼやけているので輪郭を 1 ドット足す）
7. `motion.py` 連続モーション（rpg-hero-motion 5 章）。補間でぼかさず、ドットを動かす操作だけで中間のコマを作る：
   行を抜く（呼吸・沈み）・行ごとにずらす（前傾・のけぞり）・部品をずらす（後ろ髪・裾のなびき）・宝石の色を 1 段明るく（溜め）
8. `demo/celes_fx.py` 技・術の演出デモ 第 2 版（rs-battle-fx の 6 段の時間割と派手さの決まり。リオの演出部品 `rio-rs4/fxlib.py` の色と絵をセレスに差し替え、連続コマで動かす）
   - 刻の矢：詠唱（髪と裾がはね上がる）→ 夜空に大時計・12 の星が順に灯る → 跳んで空中から針の矢 3 本（だんだん速く）→ 12 の星から一斉に矢 → スロー・白飛び・光の柱・画面を渡る衝撃の輪 → 大時計が砕けて星が降る → Weak・合計
   - 遅延の砂：大きな砂時計が裏返る → らせんで降る星の砂 → 時計の檻 → 時間停止（紫の単色で止まる）→ ひびが走って砕ける → 遅延・素早さ↓・行動順↓
   - 加速の刻：背中の大時計の針が早回し → ジグザグに走る青い残像・集中線 → 画面を渡る目盛りの輪・光の柱 → 足元から昇る青い光 → 素早さ↑・行動順↑
   - 被弾：突進の集中線と砂ぼこり → 白い影・のけぞりのコマ → 瀕死（肩で息）→ 2 撃目はスロー → 吹き飛んで倒れ、弾んで気絶（頭の上に回る星）
9. 実装の予想図：`mock.js`（実際の戦闘画面で `SPRX.frame` の `spx_celes` だけを差し替えて撮影）→ `sheet.py`

※ `mock.js` `sheet.py` は作業用フォルダで PNG と同じ場所から実行した記録。
10. `sample3.py` → `proc3.py` 星臨（マス目の境目を測って固定・銀河の色の専用パレット・白目は手で描き直す）
11. 演出 第 3 版：カメラの寄り（詠唱で術者へ寄り、放つ瞬間に引く）・回る／着地の沈みのコマ・加速の刻は後ろへ戻る間に背を向ける
12. 星臨奥義「終焉の大時計」（約 8.7 秒）：星の粒がらせんで集まる → 光の柱で星臨へ変身 → カットイン（斜めの帯・星臨の大きな姿・奥義の名）
    → 銀河へ昇る（残像）→ 天空の大時計・12 の星が灯り星座の線で結ばれる → 巻き戻し（走査線がずれる・敵が引き戻される）
    → 時間停止（紫の単色）→ 12 の星が槍になって降る → 大時計の長針が剣のように落ちる → 白飛び・光の柱・画面を渡る輪・ひび → 星の雨
    → 敵が赤く崩れる → Critical・Weak・99999 → ゆっくり降りて着地
13. 第 4 版
    - パーツ崩れの修正：体を曲げる変形を「行ごとにずらす」から「頭・胴・脚のブロックごとにずらす」（`motion.py bend`）へ。杖（手で持つ）は動かさない
    - pixelfx（`tools/pixelfx`）の 10 種をセレスの色で焼いて重ねる（`demo/bake_fx.sh` → `demo/out/fx/`。git の対象外なので最初に実行する）
      星臨のオーラ（銀河の渦）・光輪・金の陣／時間停止・遅くなった印／星の雨・光の柱・解放／光の球／杖に集まる光
    - 描画に「体の奥・手前に絵の部品を重ねる」段（`props_back` / `props_front`）を足す
    - 遅延の砂：線の砂時計 → ドット絵の砂時計（`hourglass()`：金の枠と星の飾り・ガラスの照り・積もる砂・落ちる筋・ひび）
      → pixelfx の時間停止（文字盤が止まって色が抜け、ひびが入って砕ける）→ 遅くなった印が残る
    - 星臨奥義：通常の文字盤・着弾をやめ、星臨だけの部品（天球儀の時計・金の陣・金の時間停止・星の雨・超新星）に。
      星臨のまとい（足元の金の陣・体のまわりを昇る銀河の渦・頭上の光輪・昇る星屑）を最後まで。
      途中で通常の姿に戻る不具合（着地のコマが通常の絵だった）を直し、星臨の着地・回る・浮遊のコマで動かす
14. 第 5 版
    - 星臨：服の星をコマごとに描き替える処理（チカチカの原因）をやめ、きらめきは体の上でゆっくり明滅する光の点で出す。
      左右反転で回るコマ（カクカク・何度も向きが変わる原因）を外し、奥義の動きを 1 本の道筋（`Shuen.path`）にする：
      変身の浮遊 → タメ 1（地面近くまで沈み、金の光を足元へ吸い込む）→ 弧を描いて一気に昇る（踏み切りの輪・砂ぼこり）
      → 空で浮遊 → タメ 2（少し昇って後ろへ引き、杖の先に金の光が集まる）→ 振り下ろす → 余韻 → ゆっくり降りる → 着地の沈み
    - 刻の矢：時の矢を作り直す（`arrow2`：細る光のリボンの尾・らせんの星・金と白の細る軸・時計の針の穂先・尾の星）。
      溜めで 3 本が 1 本ずつ現れて宝石のまわりを回り、溜めの終わりに敵へ向きをそろえる → 1 本ずつ発射の閃光と輪・術者が反動で後ろへ
      → 矢が刺さって光る → 歯車の輪にはじける（`arrow_stuck`）。一斉射の 12 本も同じ矢で、時計の針のように中心を指して刺さる
