# セレス 48px（ゲーム実装案その2）

ロマサガRS風（リオ）とは別のスタイル。下絵 4 枚（正面・横向き・構え・瀕死）の全体はそのままに、48×48 のゲーム素材に仕上げたもの。

- `out/celes48_{front,side,ready,dying,ko}.png` … 48×48・透過 PNG（足元を下端にそろえる）。`ko` は戦闘不能（手描きの新規）
- `out/celes48_sheet.png` … 5 コマを横に並べたシート（240×48）
- `out/celes48_mockup.png` … ゲーム実装の予想図（実際の戦闘画面でセレスの絵だけを差し替えて撮影：待機・コマンド選択・瀕死・戦闘不能）
- `out/celes48_preview.png` … 下絵との比較（8 倍）と実寸・2 倍
- `src/sketch_*.png` … 下絵（2400px の JPG）を 36px のマス目から元の解像度（48×65）に戻したもの

## 手順
1. `sample.py` 下絵のマス目（36px）を見つけ、マスの中央の中央値で 1 ドットに戻す（高さ約 53 ドット）
2. `build.py` 背景を外側から透過、4 枚共通のパレット（32 色：k-means＋肌・瞳・涙の色を固定で追加）に減色
3. `shrink.py` 背景の白い隙間を透過、上下の行と重複の多い行を 5 行抜いて高さ 48 に（顔の行は抜かない）
4. `clean.py` 足元のにじみ（灰色の行・裾の茶色）を取り除き、足元を下端にそろえる
5. `eyes.py` 白目を 1 ドットずつ入れる（正面は外側に白目・横と構えは瞳の後ろに縦の白目・瀕死は半分閉じた目）
6. `ko3.py` 戦闘不能：後ろへ吹き飛ばされて仰向けに倒れる。帽子は足の後ろに落ち、杖は手前に転がって宝石は光を失う。部品（帽子・髪・体・靴・頭・杖・腕）を奥から順に重ねる
7. `mock.js` 予想図の撮影（`SPRX.frame` の `spx_celes` だけを 48px の絵に差し替える。待機＝横・自分の番＝構え・HP 25% 未満＝瀕死・倒れ＝戦闘不能）→ `sheet.py` で 1 枚にまとめる

※ スクリプトは作業用フォルダで `out/` の PNG と同じ場所から実行した記録。
