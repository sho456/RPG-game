# 原画の依頼表（ドット絵刷新・残り分）

提供いただいた原画（黒炎竜ヴォルガノン／灰狼／仲間12人全員）は、変換してゲームに実装済みです。
残り（敵38体・街の住人4人）も同じ方法で描いていただければ、こちらで変換・組み込み・動きの実装を行います。
**見本と同じ描き方・同じ条件**で描いていただくと、追加の手直しなしでそのまま入ります。

---

## 1. 共通の条件

| 項目 | 敵・ボス | 味方 |
|---|---|---|
| 向き | **右向き**（斜め前から見た構図。見本の竜・狼と同じ） | **左向き**（見本の剣士と同じ） |
| 背景 | 単色（白 `#ffffff` か、キャラに使っていない無地の色）または透明 PNG | **透明 PNG**（ポーズ同士は 20px 以上離す） |
| 解像度 | 長辺 600px 以上（見本は 1 ドット＝約 4〜6px で描かれている） | 立ち姿の高さ 250〜300px 程度（見本は 289px） |
| 絵柄 | 見本と同じ「ドット絵風の高解像度画像」。輪郭は暗い色、光は左上から | 同左 |
| 1 枚に含めるもの | キャラ 1 体だけ。文字・影・地面・エフェクトは描かない | ポーズを横一列に並べたシート |
| 切れ・はみ出し | 尾・翼・武器の先まで画面内に収める | 同左 |
| ファイル名 | `<ID>.png`（例：`slime.png`） | `hero_<ID>_poses.png`（例：`hero_gald_poses.png`） |

### 大きさの目安（ゲーム内の出来上がり）
こちらで原画から縮小して、下の大きさのドット絵にします。原画の描き込みはそのまま縮小されるので、細部は大きめに描いてください。

### 味方のポーズ（見本の剣士シートと同じ並び＋できれば追加）
**必須7種**：①正面立ち ②構え（外套なびく） ③構え（武器を構える） ④踏み込み攻撃 ⑤跳び込み ⑥背面 ⑦倒れ
**あると良い5種**（無い場合はこちらで①〜⑦から作ります）：⑧詠唱（武器や手を掲げる） ⑨被弾（のけぞる） ⑩瀕死（膝をつく） ⑪勝利 ⑫歩き（片足を上げた2コマ）
星臨（覚醒）は、こちらで配色を変えて作ります。専用デザインにしたい場合は別シートでお送りください。

### 敵のポーズ
1 枚で足ります（呼吸・踏み込み・のけぞり・点滅・崩れはプログラムで付けます）。口の開閉など絵が変わる動きを付けたい場合は、同じ構図で差分をお送りください。
