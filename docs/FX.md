# 戦闘演出の全面刷新（ver1.0 まで）の計画と作り方

戦闘の仕組みの見取り図は [BATTLE.md](BATTLE.md)。ここは ver0.34 から始めた演出の刷新について、
**どこに何があるか・技の演出の足し方・段階ごとの計画と進み具合** をまとめたもの。

絵（エフェクト・背景）はすべてコードで描いている（画像生成は使っていない）。味方・敵の絵は従来どおり提供原画から作ったもの。

---

## 1. ファイル

| ファイル | 中身 |
|---|---|
| `js/battle/core.js`（`BX`） | 設定・時間の倍率・品質・粒子（使い回し）・エフェクトの一覧・カメラ・残像・暗転 |
| `js/battle/prim.js`（`BXP`） | エフェクトの部品。値（形・色・動き・規模）を変えて組み合わせる |
| `js/battle/seq.js`（`BXS`） | 技の演出の台帳と再生。ver0.19 の振り付け（`js/ver19.js`）への差し込み（`V19.ext`） |
| `js/battle/data/fx-*.js` | 技・敵・ボス・星臨ごとの演出データ |
| `js/battle/viewer.js` | 設定の行（`CFGX`）・星臨演出の長さ・演出ビューア（`BXV`） |
| `js/battle/version.js` | 版表示・お知らせ |
| `css/battle.css` | 演出ビューア・星臨演出の省略 |

既存のファイルに入れた変更は「差し込み口」だけ：`js/ver19.js`（`pre`・`strike`・`onHurt`・`finish`・`pop` から `V19.ext` を呼ぶ）、
`js/town.js`（速度を ×1・×2 に）、`js/ver17.js`（設定画面に行を足す `CFGX`）、`js/v23.js`（星臨の文字演出を設定に合わせて縮める）。

## 2. 技の演出の足し方

`js/battle/data/` のファイルに 1 件書くだけ。書き方の全項目は `js/battle/seq.js` の冒頭。

```js
BXS.def('koujin',{kind:'melee',big:1,
 pre:{ms:0,do:[[0,'fx','glint',{on:'ah',ramp:'光'}],[0,'fx','gather',{on:'a',ramp:'光',n:9}]]},          // 予備動作
 strike:{ms:240,do:[[0,'pose',{f:'ready'},140],[150,'pose',{f:'lunge'},50,'in'],[150,'ghost',{n:3}]]},  // 発動（終わりが命中）
 impact:[[0,'fx','crescent',{ramp:'光',r:16}],[70,'fx','cut',{ramp:'光',len:38}],[0,'shake',7]],        // 命中
 after:{ms:120,do:[…]}});                                                                              // 余韻
```

- 探す順：`'キャラ:技'` ＞ `'技'` ＞ `'キャラ:cat:区分'` ＞ `'cat:区分'`。定義が無い技は従来の振り付けのまま動く。
- キー：技は `SK` のキー、通常攻撃は `'atk'`（`'rio:atk'`）、敵の行動は `'ea:claw'`（`'slime:ea:claw'`）。
- 部品（`BXP`）：`crescent` 三日月の斬撃／`cut` 一文字の斬り筋／`stab` 突き／`flare` 星形の閃光／`shock` 衝撃波／`sparks` 火花／`dust` 砂ぼこり／
  `circle` 魔法陣／`gather` 収束／`rise` 立ちのぼる粒／`pillar` 光の柱／`bolt` 稲妻／`shards` 氷の結晶／`flame` 炎／`gale` 旋風／`spikes` 岩の槍／
  `orb` 球／`beam` 光線／`proj` 飛び道具／`speedlines` 集中線／`petals` 花びら／`glint` きらめき／`ward` 守りの膜。
- 色：`ramp` に属性名（`'炎'` `'氷'` …、`'heal'` `'buff'` `'debuff'` `'star'`）、色 1 つ、または色の配列（明るい → 暗い）。
- きまり：**1 コマで読める形**・**命中の瞬間に形が完成する**・**熱い色 → 冷たい色へ、透明にせず小さくして消す**・全画面を覆う塗りは短く。

## 3. 確認のしかた

1. 開発者メニュー →「ver0.34 演出ビューア」。味方の技・敵の行動・星臨・状態を、相手・数・速度を選んで何度でも再生する（★＝専用の演出あり）。
2. `python3 -m http.server 8765 &` → `node tools/smoke.js --fx`：全画面・全種類の敵との戦闘に加えて、
   味方全員の全技・星臨（通常／短縮／省略）・敵の全行動を 1 回ずつ再生し、エラーと「演出が終わらない」を集める。

## 4. 設定（`G.set.fx`）

| 項目 | 値 | 効き |
|---|---|---|
| 星臨演出 `aw` | `full` 通常／`short` 短縮／`skip` 省略 | 短縮・省略のあいだ、演出の待ち時間を縮める（`BX.scaled`） |
| 演出の品質 `q` | `auto` 自動／`high`／`std`／`low` | 粒の数と上限（高 900・標準 520・低負荷 200）、カメラの寄りの強さ。自動は描画の遅れを見て下げる |
| 画面の揺れ `shake` | 2 あり／1 控えめ／0 なし | `B.shake` の上限 |
| 画面の点滅 `flash` | 1 あり／0 控えめ | `B.flashBg` の上限 |

戦闘速度は ×1・×2 の 2 段階（`SPD[4]` は自動点検の早回しだけが使う。画面からは選べない）。

## 5. 段階ごとの計画と進み具合

| 段階 | 版 | 内容 | 状態 |
|---|---|---|---|
| P0 基盤 | 0.34 | 演出の台帳・部品 23 種・粒子の使い回し・品質・カメラ・残像・設定・演出ビューア・点検（--fx）。リオの通常攻撃と 3 技 | **済** |
| P1 キャラモーション | 0.35 | 1 枚絵を骨格で分けて曲げる動き。待機・移動・攻撃・防御・詠唱・被弾・瀕死・戦闘不能・勝利・復活を 12 人ぶん | 未 |
| P2 技演出 | 0.36〜0.37 | 味方の全技と通常攻撃を固有の演出に。差別化チェック（組み合わせの重複を機械で見つける） | 未 |
| P3 星臨・共鳴 | 0.38 | 12 人の変身の流れ・専用背景・カットイン。星臨中のコマンド 33・共鳴技 29。通常／短縮／省略を作り込む | 未 |
| P4 敵・ボス | 0.39 | 種族の型と個体ごとの上書き。敵の行動 41 種。ボス 32 体の登場・予兆・形態変化・撃破 | 未 |
| P5 戦闘エフェクト | 0.39 | ダメージ表示・属性相性・回復・バフ／デバフ・状態異常・障壁・行動の遅延／加速 | 未 |
| P6 最適化・仕上げ | 1.0 | 粒の上限の詰め・光の部品の事前描画・低負荷モードの計測・全体の点検 | 未 |

味方のモーションは「1 枚絵＋骨格で曲げる」方式で進める。あとから原画のコマが届いたら、そのポーズから自動で置き換わる
（[PIPELINE.md](PIPELINE.md) 3-3・5 章）。
