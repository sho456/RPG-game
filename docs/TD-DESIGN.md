# タワーディフェンス（TD）設計書 ― 灯守の防衛線

コマンドRPG（ver0.49 まで）から TD へ移行するための正本の設計書。数値・用語・データの書式はここを基準にする。
決定事項（2026-11-19）：**スマホの縦画面**／**横から見た道（ジグザグに折り返すレーン）**／**数値の尺度を引き直す**／**灯域を採用**。

## 1. 遊びの芯

- 虚蝕（敵）が道を歩いて、画面の下の **灯（拠点）** を目指す。灯守（仲間）を **台座** に置いて止める・倒す。
- **灯域**：灯の光が届く範囲。台座は光の中でしか使えない。光の外になった台座のユニットは攻撃 −40%。
  - 灯は半径 `light.r` の光を出す。リオ・ノアは自分の周りにも光を出す（光の鎖で上の段へ届かせる）。
  - 「虚蝕を撒く」敵は生きている間、1 体につき灯の光を毎秒 1.5 削る（最小は元の 60%）。倒すと 10 戻り、虚蝕がいない間は毎秒 4 ずつ元に戻る。
- **灯火 7**：拠点の残り（旧 LP 7 を引き継ぐ）。敵が灯に届くと 1、ボスは 3 減る。0 で敗北。
- **灯力**：配置の資源。はじめ 10、0.9 秒ごとに +1、撃破で +1（ボス +10）。撤退で配置コストの半分が戻る。
- **星片**：撃破で落ちる。10 たまると、置いている仲間 1 人の **星臨**（戦闘中 1 回の必殺技）を使える。
- 速度 ×1／×2、一時停止中も配置・撤退・星臨の指示ができる。

## 2. 画面（縦 9:19 前後。論理座標は 360×520 の戦場＋上下の帯）

```
┌ 上の帯：WAVE 2/4 ・ 灯火 ◆7 ・ ⏸ ×2 ┐
│ 戦場（canvas）                         │  道は左上から入り、段ごとに左右へ折り返して下の灯へ
│   ─────────────→                       │  台座：道の上（前＝止める）と段の間（後＝射る・術・支える）
│   ←─────────────                       │  灯域の外は暗く沈む（虚蝕の灰紫）
│   ─────────────→   ◎灯                 │
├ 下の帯：灯力 23 ▮▮▮ ・ 星片 ★6/10     ┤
│ 手札 8 枚（顔・コスト・待ち時間の扇）  │
└────────────────────────────────────────┘
```
- 敵は横向きの原画のまま、進む向きに合わせて左右を反転する（見下ろしの絵は不要）。

## 3. 数値の尺度（RPG 版の 9999 万・Lv60 以降のインフレは使わない）

| 項目 | 目安 |
|---|---|
| 仲間の HP | 400〜1,400 |
| 仲間の攻撃 | 40〜120（Lv で +3%/Lv） |
| 1 撃のダメージ | 数十〜数百（星臨で数千まで） |
| 敵の HP | 雑魚 150〜600、中ボス 3,000〜、大ボス 8,000〜 |
| 移動 | 18〜60 px/秒（戦場の幅 360） |

**ダメージ**：`攻撃 × 倍率 × 攻撃/(攻撃+防御) × 属性 × 会心`。属性は敵の弱点 ×1.5・耐性 ×0.5。
物理は敵の `def`、術は `res` を防御に使う。

## 4. 仲間（役割）

| 役割 | 台座 | 仲間 | 既定 |
|---|---|---|---|
| 守る | 前 | ガルド・バルザ・ヴァルク | 止める数 2〜3、射程 近、コスト 14〜18 |
| 斬る | 前 | リオ・シオン・ハクア・ジン | 止める数 1、射程 近、コスト 8〜12 |
| 射る | 後 | エルナ | 射程 長、コスト 12 |
| 術 | 後 | ミレイユ・クロウ | 範囲、射程 中、コスト 13〜14 |
| 支える | 後 | ノア・セレス | 回復・遅延・加速、コスト 11〜12 |

- 能力値 7 種 → 攻撃（武器の主能力：腕力または知力）・HP（体力）・防御（体力）・術防（精神）・攻撃間隔（素早さ）。
- 技は 1 人 1 つ（RPG 版の技・術の名前を使う）。時間でチャージし、たまると自動で出る。
- 星臨は RPG 版の星臨の名前（`AW[id].name`）。
- 正本：`js/td/data.js`（`TDD.HERO`）。

## 5. 敵

- `ED` から自動で変換（`TDD.foe`）：HP＝`mhp×1.2`、攻撃＝`atk`、防御＝`def`、術防＝`res`、移動＝`14+spd×2.4` px/秒、弱点＝`weak`。
- 型（`TDD.TRAIT`）：群れ・重装・霊体・飛行・虚蝕を撒く・盾持ち・ボス。キーごとに付ける。
- ボス：`ai.every`（N ターンごと）→ N×2 秒ごとに仕掛け（溜め攻撃・手下を呼ぶ `summon`）。灯に届くと灯火 −3。

## 6. ステージの書式（`TDD.STAGE`）

```js
{id:'td0_4', q:'q0_4', name:'灰狼の頭目', lv:4,
 path:[[x,y],...],                 // 道の折れ線（戦場の座標）
 base:[x,y], light:{r:230},       // 灯の位置と光の半径
 pads:[{id:'f1',k:'f',s:120},     // 前の台座：道の上（始点からの距離 s）
       {id:'b1',k:'b',x:..,y:..}],// 後ろの台座：段の間
 cost0:10, cap:6,                 // 灯力のはじめ・配置の上限
 waves:[{e:[[秒,'kind',数,間隔],...]}],
 star:{time:150}}                  // 星 3 の条件（灯火を減らさない・時間・クリア）
```
- 難易度は `tools/td_sim.js` で自動の配置（AI）に 30〜100 回戦わせ、勝率と灯火の残りで合わせる（スキル `td-sim-balance`）。

## 7. コードの構成（上書きの連鎖に足さない）

| ファイル | 役割 |
|---|---|
| `js/td/data.js`（`TDD`） | 仲間・敵の変換、ステージ、数値の定数 |
| `js/td/sim.js`（`TDS`） | 戦闘のシミュレーション。DOM・時計に触れない（固定刻み 1/30 秒、乱数の種つき）。自動の配置（`TDS.bot`）も |
| `js/td/view.js`（`TD`） | 画面：戦場の描画（SPX の原画）・上下の帯・操作・リザルト。入口 `TD.open(stageId)`、`index.html#td` |
| `css/ui/tokens.css` | デザイントークン（色・文字・角・影）。新しい画面はこれ以外の色を使わない |
| `css/ui/td.css` | TD の画面 |

本編の `startBattle` 系（ver16〜v38・`js/rs/*`）には触らない。P4 で TD が置き換えたあと削除する。
