# アートバイブル（ドット絵刷新）

## 0. 方針（確定）
- **絵の正解はユーザー提供の原画**。原画（高解像度のドット絵風画像）をゲームの格子へ縮小・減色してスプライトにする。
  自作の手続き生成ドット絵は不採用（パイロット第1〜4版。`tools/pxl/` に記録として残す）。
- 参考作品（SFC版ロマサガ1・3、ロマサガRS）からは**描き方・構図・密度**だけを学ぶ。スプライトの複製・トレースはしない。
- 原画が届いていないキャラは、届くまで旧リグ（`js/dot-*.js`）のまま（`docs/art_request.md` で依頼中）。

## 1. 光源と陰影
- 光源は**左上固定**。原画もこの向きで描いてもらう（依頼表に明記）。
- 陰影は原画のものをそのまま使う。縮小は面積平均（ぼかしではなく画素の平均）、減色はディザなし。
- 派生ポーズ（被弾・瀕死など）は原画の解像度で回転・変形してから縮小するので、陰影の向きは数度しかずれない。

## 2. 輪郭
- 外周は**共通の暗色 1 ドット** `#221c28`（わずかに紫寄り）。縮小後に付け直す。
  - 縁の画素がすでに暗い（明度 62 未満）ならその縁を輪郭色に置き換え、明るい縁の外側にだけ 1 ドット足す（線が太らない）。
- 内側の線は原画の描き方に従う（色付きの暗部で区切る）。輪郭の内側に孤立した 1 ドットの輪郭色は除去する。

## 3. パレットと色数
- **キャラごとに 1 つの共有パレット**（全フレーム・全サイズで同じ色）。並びは暗→明。
- 色数上限：通常敵 26〜28 色、ボス 35 色、味方 31 色（いずれも輪郭色込み）。
- 色替え（パレットの写像）：
  - 星臨：ビルド時に専用パレットを作る（リオ＝紺の外套→白銀の青、金→白金、赤→金。肌・輪郭は不変）。
  - 試練の幻影（`tr_`）：紫 `#5a2aa0` へ 55% 寄せて暗く。虚蝕化（`vo_`）：灰紫化＋強い赤は `#e080ff`。
  - これらは「同じキャラの状態」の表現。上位種・亜種は色替えで作らない（依頼表で別造形を依頼）。

## 4. ドットの大きさ（全キャラ共通）
- **戦闘**：1 ドット＝端末の画素 `round(devicePixelRatio)` 個（≒ 1 CSS px）。新スプライトも旧リグも同じ幅で描く。
  エフェクト（`FX19`）と粒子は従来の幅（≒1.5 CSS px）のまま。
- **探索・街**：1 ドット＝論理 1 px（≒ 2.17 CSS px。マップのタイルと同じ格子）。そのため探索用は別サイズを原画から作る。
- ドット絵を拡大・縮小して表示しない。大きさの違いは、原画から別々に縮小した複数サイズの中から最も近いものを選んで出す。

## 6. アニメーション
- **味方**（原画 7 ポーズ＋派生 8 ポーズ＝計 15）：
  正面・構え（外套）・構え（武器）・踏み込み・跳び込み・背面・倒れ（原画）／
  立ち（武器なし）・歩き a／b・詠唱・被弾・瀕死・防御・勝利（派生）。
  戦闘の振り付け（`js/ver19.js` のキーポーズ）は値から絵を選ぶ（`SPX.heroFrame`）：
  走り→跳び込み／振りかぶり→詠唱（剣を立てる）／斬撃・突き→踏み込み／発動→構え（外套）／被弾→被弾／瀕死→瀕死／防御→防御／勝利→勝利／戦闘不能→倒れ／待機→構え（武器）＋呼吸。
- **敵**：1 枚絵を整数ドットで動かす（SFC版ロマサガと同じ方式）。
  呼吸＝上半身を 1 ドット沈める／踏み込み＝前へずらす／前傾・のけぞり＝行ごとに整数ドットずらして傾ける（最大 6 ドット）／
  被弾＝白く点滅＋ノックバック／撃破＝網点で溶ける（既存の演出）。
- 全フレームで足元（アンカー）をそろえる：最下段付近の不透明画素の左右中央を接地点にする（倒れは左右中央）。

## 6b. 仲間12人の構成（提供シート）
- 原画シートの 12〜13 ポーズ（待機・正面・背面・通常攻撃・防御・歩き・走り・魔法詠唱・被弾・瀕死・勝利・戦闘不能）を、
  ゲームの絵（構え・正面・背面・踏み込み・防御・歩き・跳び込み・詠唱・被弾・瀕死・勝利・倒れ）へそのまま対応させる。
- 全員を**左向き**にそろえる（右を向いて描かれたポーズは左右反転）。決闘の敵として出るエルナ・ヴァルクは同じ絵を右向きで描く。
- 頭身：正面の目→足元の長さをリオにそろえ、元のリグの背丈の比を掛ける（ドワーフのバルザは小さく、竜人ヴァルクは大きく）。
- ジンは相棒ポポを同じ絵に含める（足元の接地点はジン本人の足で求める）。
- 星臨の姿：原画シートの「覚醒した姿」を、通常の姿と同じ縮尺・専用パレットで別データ（`<id>_K`）にする。
  輪郭の外まで描かれた光の翼・光輪・炎は、ガルド・ノア・ミレイユ・ヴァルクは背景色だけを抜いて残し、ほかは輪郭の内側を使う。
  戦闘では 1 枚絵を整数ドットで動かす（前へ出る・前傾・のけぞり・上下・呼吸）。図鑑の立ち絵・顔グラ・カットインも同じ絵。
- 戦闘不能時と探索・街の星臨の配色（パレット置換）：ガルド＝赤→蒼、ミレイユ＝紅→青、セレス＝紫を明るく、ノア＝白金に光る、エルナ＝青→白、
  ハクア＝緋→紫紅・白衣を氷色、バルザ＝赤を炎色、クロウ＝紫→群青、シオン＝緑→翠青、ジン＝緑→暗金、ヴァルク＝赤→濃紺（原画の覚醒姿の色に寄せる）。

## 7. 派生ポーズの作り方（原画の解像度で加工 → 同じ変換）
| ポーズ | 作り方 |
|---|---|
| 立ち（武器なし） | 正面から刃の多角形を消す |
| 歩き a／b | 立ちの手前／奥の脚を 1 歩ぶん持ち上げる |
| 詠唱 | 正面の刃を切り取り、柄を軸に回して上向きに付け直す |
| 被弾 | 構え（武器）を足元を軸に 11° のけぞらせる |
| 瀕死 | 構え（武器）の下半身を縮めて膝を沈め、前へ 9° 崩す |
| 防御 | 構え（武器）を少し沈め、6° 後ろへ重心を移す |
| 勝利 | 構え（外套）を 4° 伸び上がらせる（戦闘では跳ねる動きと組み合わせる） |

## 9. 自己レビューのチェックリスト（実施方法）
- シルエット：`docs/sheets/spx_*.png`（全サイズ・全フレーム）と比較シートの黒塗りで確認
- 実表示サイズ：`tools/verify_spx.js`・`tools/verify_ui.js`（dpr 2／3）で戦闘・探索・街・図鑑・編成・顔を撮影
- 全フレームの一貫性：`tools/pose_sheet.js` で全キーポーズの選ばれ方と接地をそろえて確認
- 旧アセット：`assets_backup/old_sprites/` に改修前の描画を保存（旧リグのコードは削除していない）
