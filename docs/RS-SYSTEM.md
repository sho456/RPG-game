# 戦闘システム（ver0.38〜）

ver0.37 で戦闘を『ロマンシング サガ リ・ユニバース』（以下 RS）の仕組みを分析して作り直し、ver0.38 でシステムを整理・統合した。
取り入れたのは**仕組みと呼び名**だけ。技名・キャラ・絵・音は、この作品のものを使っている。

| ファイル | 中身 |
|---|---|
| `js/rs/data.js`（`RSD`） | 攻撃属性・武器種・能力値・キャラ設定（武器種・LP・BP）・技・術・アビリティ・星臨・陣形 |
| `js/rs/core.js`（`RSC`） | 能力値の計算・命中率・追加効果の成功率・技の習得とセット・アビリティ・陣形の適用・セーブ |
| `js/rs/battle.js`（`RSB`） | ターン・BP・HP/LP・行動順・ひらめき・熟練・アビリティの効果 |
| `js/rs/ui.js`（`RSU`） | コマンド欄（RS 風）・下のボタン・キャラ詳細（能力・技・術・星臨） |
| `js/v38/core.js`（`V38`） | 属性名の正規化・敵の LP 攻撃・通常攻撃・セーブの移行・LP の全回復 |
| `js/v38/battle-ui.js`（`V38B`） | 戦場の配置（陣形）・コマンド入力中のスライド・HP/BP 表示（ターンの始めだけ）・連続戦闘の移行演出 |
| `js/ui/board.js`（`BOARDUI`） | 星盤・天星盤の画面（ver0.39 で正本を 1 本に） |
| `js/ui/party.js`（`V38P`） | 編成画面・陣形（ver0.41 で移動） |
| `js/v38/menu.js`（`V38M`） | ホームのタブ整理・戦闘中の撤退・版表示・お知らせ |
| `css/v38.css` | 上の画面の見た目 |

## 1. ver0.38 で廃止・統合したもの

| 廃止 | 扱い |
|---|---|
| オーバードライブ（OD） | 処理・ゲージ表示・作戦タブ・陣形の効果・アビリティの効果（「OD上昇」は「星臨ゲージ上昇」へ）を削除 |
| 連携 | 処理・見出しを削除。アビリティの「連携ダメ+%」は「技・術の与ダメ+%」へ |
| 共鳴技 | 発動処理・名前の表（`RESO`）・追加効果（`RFX`）・編成画面のタブ・カットインの包みを削除。レジェンド「双子星の首飾り」は「奥義の威力+30%」に |
| ジョブ | 職業データ（`JOBS`）・ジョブ画面・ジョブ経験値・ジョブのパッシブを削除。ジョブの技はキャラごとの技・術（6 種）に統合済み。育成要素は能力値の成長とアビリティに統合し、施設「星詠みの塔」は「ひらめき率+10%/Lv」に |
| 下の帯の倍速ボタン | 画面上の倍速ボタンだけに統一（設定画面の「戦闘速度」「コマンド決定」も削除） |

| 連続戦闘の合間の画面 | 敵を全滅させると自動で次の戦闘へ（撤退は戦闘中のメニュー ≡ から） |

古いセーブは `migrate` で読み替える（ジョブの記録を消す・装備の武器名を新しい武器種に・発見した弱点の属性名を新しい名前に）。

## 2. 攻撃属性（8 種）

**斬・打・突・熱・冷・雷・陽・陰**。技・術・敵の攻撃・弱点・耐性・装備（通常攻撃の属性）はすべてこの 8 つ。

| 旧 | 新 |
|---|---|
| 炎・氷・光・闇 | 熱・冷・陽・陰（名前の変更。ソースの属性名も書き換え済み） |
| 風・地 | 斬・打 に統合（敵の弱点が重なる場合は 1 つにまとめる） |
| 属性なし（無） | 術は陰、敵の物理攻撃は打 |

弱点 ×1.7・耐性 ×0.5（従来どおり）。演出の色（`ELC`・FX のランプ）は旧名の色を新しい名前に引き継いでいる。

## 3. 武器種（8 種）

武器種と攻撃属性は別の概念。武器種は**通常攻撃の属性**と**技の威力に使う能力値**を決める。

| 武器種 | 通常攻撃 | 技の威力の配分 | 使い手 |
|---|---|---|---|
| 剣 | 斬 | 腕力70%＋器用さ30% | リオ |
| 短剣 | 突 | 器用さ80%＋腕力20% | シオン |
| 大剣 | 斬 | 腕力100% | ガルド・ヴァルク |
| 斧 | 斬 | 腕力90%＋器用さ10% | バルザ |
| 体術 | 打 | 腕力50%＋素早さ50% | ハクア |
| 弓 | 突 | 器用さ80%＋腕力20% | エルナ |
| 杖 | 術（魔弾・得意属性） | 腕力60%＋器用さ40%（技を使う場合） | ミレイユ・ノア・クロウ・セレス |

**クロウの鎌杖**：武器種は**杖**、形は**大鎌**。杖と鎌の両方の機能を持つ。
- 通常攻撃が 2 つ：「通常攻撃（杖）」＝魔弾（術・陰・知力）／「通常攻撃（鎌）」＝鎌の一閃（斬・技・腕力と器用さ・与ダメの 10% を吸収）
- 装備は魔力に加えて攻撃も上がる（攻撃は魔力の 60%）。名前は「〜の大鎌」、アイコンも大鎌（専用の名前表 `WNS.crow`）
- AUTO は相手の防御・精神と弱点を見て、通る方の通常攻撃を選ぶ。リピートは最後に使った方を繰り返す
- データ：`RSD.HERO.crow.shape`・`alt`、処理：`ALTATK`・`basicsOf`（js/v38/core.js）
| 双剣 | 斬 | 器用さ60%＋腕力40% | ジン |

装備の武器名も新しい武器種に合わせた（体術の武器は「手甲」）。短剣のアイコンを追加（`js/items/icons36.js` の `W.dagger`）。

## 4. 能力値（7 種）

| 能力値 | 役割 |
|---|---|
| 腕力 | 剣・大剣・斧・体術などの物理攻撃の威力 |
| 体力 | 技（物理攻撃）への防御力（内部値：防御） |
| 器用さ | 攻撃の命中率と、短剣・弓・双剣の威力 |
| 素早さ | 行動順・回避率・命中率と、体術の威力（内部値：素早さ×3） |
| 知力 | 熱・冷・雷などの術の威力と命中率。状態異常・能力変化・耐性変化の付与成功率（内部値：魔力） |
| 精神 | 術への防御力。状態異常・能力変化・耐性変化への耐性（内部値：精神） |
| 魅力 | 回復を受けたときの回復量・回復アビリティの回復量・状態異常の付与成功率 |

旧来の「愛」は魅力に統合した。会心率は器用さから外し、装備・アビリティだけで上がる（役割の重複をなくすため）。

**数式（`RSC`）**
- 命中率（技）：`0.94 ＋ 0.12×(器用さ÷自分の能力値の平均 − 1) ＋ 0.12×(素早さ差の比)`、75〜100%
- 命中率（術）：`0.95 ＋ 0.08×(知力÷平均 − 1) ＋ 0.1×(知力 対 精神の比)`、80〜100%
- 追加効果の成功率：基本の確率 ×（0.4〜1.6）。状態異常は知力と魅力の平均、能力変化・耐性変化は知力で、相手の精神と比べる。確率の書いていない効果は必中
- 回復を受ける量：×(0.85〜1.45)（魅力÷平均）。回復アビリティの量：×(0.85〜1.35)（持ち主の魅力）
- 敵の能力値は旧来の値から作る（腕力＝攻撃、体力＝防御、知力＝魔力、精神＝精神、素早さ・器用さ＝素早さ×3×レベルの伸び）

目安（Lv1〜80）：味方の命中 84〜100%（大剣・斧はやや外れやすい）、敵の命中 87〜97%。

**バランス**：Lv1 の時点で、武器種の配分から計算した「技の威力」が旧来の「攻撃」と同じになるよう主能力を自動で決める（`RSC.pf`）。

## 5. HP・LP・BP

| | 仕様 |
|---|---|
| HP | 最大HPの **30% 以下で瀕死**（HP 表示が赤く点滅）、**0 で気絶**。回復技・術・アビリティで回復 |
| LP | 全員 7。**減るのは、気絶したとき（-1）と、一部の高難易度ボス（LP を削る技を持つ Lv50 以上のボス）の攻撃に当たったときだけ**（ver0.46g。気絶中の追い打ち・回復術では減らない）。0 になるとその戦闘では復活できない。表示は回復と同じ 3 段目に赤い「LP-1」（ダメージの数字と被るときは約 0.6 秒あとに） |
| 復活 | LP が 1 以上なら、**回復術（単体）**・道具・奥義（聖機の福音）で復活できる |
| BP | 技・術の消費。キャラごとに **初期・最大・毎ターンの回復** を持つ（下の表）。ver0.45 で装備の「BP回復力」を廃止し、初期 +2・回復 4（重装の 3 人は 3）に見直した。星盤の BP回復力 5 ごとに毎ターン +1（最大 +2） |

| キャラ | LP | BP 初期 / 最大 / 回復 |
|---|---|---|
| リオ・シオン・エルナ・ハクア・ジン | 7 | 8 / 20 / 4 |
| ミレイユ・ノア・セレス | 7 | 9 / 24 / 4 |
| クロウ | 7 | 9 / 22 / 4 |
| ガルド・バルザ | 7 | 7 / 18 / 3 |
| ヴァルク | 7 | 7 / 20 / 3 |

消費：威力ランク E1・D2・C3・B4・A6・S8・SS10・SSS12（全体攻撃は +2）。B の技は毎ターン、A 以上は貯めて使う回り方。

## 5.5 アビリティ（ver0.45：3 段階）

- 1 人 3 つ（解放 Lv1・25・50）。解放から +20Lv ごとに 1 段階（最大Ⅲ）。星盤・天星盤の強化ノードで +1 段階。データは `js/rs/abilities.js`
- **段階Ⅲで固有名の特殊効果【…】** が付く（例：ガルド【仁王立ち】かばう、エルナ【迅雷】マヒ、クロウ【死神の鎌】とどめ、シオン【先手必勝】）
- 追加した効果：かばう（cover）・マヒ（para）・暗闇（blind：命中 −30%）・毎ターンの始めの強化（tstart）・行動後の BP 回復（actbp）・1 ターン目に最初に動く（prio1）・回避したら反撃（evct）・気絶した味方を起こす（autorev）・回復した味方の弱体解除（healcl）・仲間の星臨でゲージ（agshare）・反撃でスタン（ctst）・こらえたときに強化（gutsbuff）・とどめ（execute）・HP が半分を切ったら強化（hpbuff）・味方全体の被ダメ軽減（allycut）
- 効果の用語（スタン・挑発・追撃・【固有名】など）は緑で、タップで説明（`js/ui/keywords.js`）

## 5.6 装備（ver0.45：基礎ステータスだけ）

装備が上げるのは HP・腕力・体力・器用さ・素早さ・知力・精神・魅力だけ（`js/data/equip7.js`）。会心率・BP回復力などの付加能力は付かない（古いセーブは近い基礎ステータスへ置き換え）。属性耐性は防具の六角の印（青＝強い・赤＝弱い）で示す。

## 6. 陣形

陣形は並び順（1〜4 番目）ごとに **立ち位置** と **能力値の補正** を持つ。立ち位置はそのまま戦闘の配置になる（前列ほど敵に近い）。

| 陣形 | 立ち位置 | 補正 |
|---|---|---|
| 星環の陣 | ひし形 | 1：体力+10%／2：素早さ+10%／3：精神+10%／4：知力+10%・初期BP+1 |
| 天穹の陣 | 前 2・後 2 | 1・2：腕力+15%・狙われやすい／3・4：知力+15% |
| 城塞の陣 | 先頭 1・後ろ 3 | 1：体力+30%・強く引きつける／2・3：精神+10%／4：体力+10% |
| 疾風の陣 | 斜め一列 | 全員：素早さ+20%・初期BP+1・体力−10% |
| 鶴翼の陣 | 翼の形 | 1・4：器用さ+15%／2・3：知力+15% |
| 祝星の陣 | ジグザグ | 1：体力+10%／2・3：魅力+20%・毎ターンBP+1／4：精神+10% |

## 7. 戦闘画面（RS の画面の分析と対応）

| RS | この作品 |
|---|---|
| 敵は左、味方は右で向き合う | 味方は右に陣形どおり（原画は左向き）、敵は左（右向き） |
| 上の細い帯：ラウンド・ボスの名前と HP・行動順 | TURN・対象の名前と HP・弱点の 8 属性・行動順（顔のアイコン）・倍速・メニュー |
| コマンド入力中は戦場が上に寄り、下半分にコマンド欄 | 戦場（絵・HP 表示・演出の層）を `translate` で上へスライド。コマンド欄は下から出る |
| 最後のコマンドを決めると、コマンド欄が下へ抜けて戦場が全面に | 入力が終わると 0.4 秒でスライドが戻り、行動が始まる |
| コマンド欄：名前と顔・HP/LP/BP・技（属性・名前・BP・ⓘ）・戻る・AUTO | 同じ構成。下の段に「戻る（前のキャラ）・道具・交代」。技は 1 回のタップで決定 |
| 下の帯：通常AUTO・全力AUTO・リピート | 同じ（倍速は上だけ） |

## 8. 星臨（特殊アビリティ＋奥義）

ver0.37 と同じ。星臨ゲージが満タンで、行動を消費せずに発動（同時に 2 人まで）。発動中は星臨アビリティで強化され、奥義を 1 度だけ使える（BP 0）。
コマンド欄の右上の「星臨」ボタンで発動する。
