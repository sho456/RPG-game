# 戦闘システム（ver0.37〜）：ロマサガRS の分析と、この作品への組み込み

ver0.37 で、戦闘の仕組みを『ロマンシング サガ リ・ユニバース』（以下 RS）の戦闘システムを分析して作り直した。
取り入れたのは**仕組みと呼び名**だけ。技名・キャラ・絵・音は、この作品のものを使っている。

- データ：`js/rs/data.js`（`RSD`）……能力値・技・術・アビリティ・星臨・陣形
- 組み込み：`js/rs/core.js`（`RSC`）……能力値の計算・技の習得とセット・アビリティの段階・星盤の置き換え・セーブ
- 進行：`js/rs/battle.js`（`RSB`）……ターン・BP・行動順・連携・OD・ひらめき・熟練・アビリティの効果
- 画面：`js/rs/ui.js`（`RSU`）と `css/rs.css`

---

## 1. RS の戦闘システムの分析

| 要素 | RS での仕組み（分析） | 意図・効き方 |
|---|---|---|
| ターン制 | ターンの始めに味方全員の行動を選び、敵味方が**素早さ順**に動く（同じくらいの素早さだと順番がゆらぐ） | 「行動を予約して結果を見る」読み合い。素早さが行動順だけに効き、手番の回数は変わらない |
| BP | 技・術の消費。戦闘開始時の BP と、毎ターンの回復量がある。通常攻撃は消費 0 | 強い技を毎ターンは撃てない。BP を溜めるターン／吐くターンの配分が戦術になる |
| 威力ランク | 技・術の威力を E〜SSS の段階で表す。消費 BP はおおむね威力に比例 | 数値を見せず、段階で強さを比較できる |
| 連携 | 味方が続けて攻撃すると「◯連携」になり、ダメージが上がる。敵の行動が挟まると途切れる | 行動順を意識した技選び（遅い攻撃役・速い補助役の並べ方）に意味が出る |
| オーバードライブ（OD） | 戦闘で溜まるゲージ。満タンで使うと、味方が敵より先に連続で行動し、必ず連携になる | 溜めて「ここぞ」で使う大技。ボスの大技の前に倒し切るなど |
| ひらめき | 戦闘中に技を使うと、確率で派生の新しい技を閃き、その場で使う。強い敵ほど閃きやすい | 戦うこと自体が成長になる。閃いた瞬間の演出が気持ちよさの核 |
| 技の熟練（技Lv） | 使った回数で技が育ち、威力が上がり消費 BP が下がる | 使い慣れた技に愛着が出る |
| 技のセット | 戦闘に持ち込む技・術は数が限られる（スタイルごとに選ぶ） | 覚えた技の中から、敵に合わせて組み替える |
| アビリティ | 自動で効く能力。1 つに複数の効果が付き、育成で強化される | 「キャラの個性」をパッシブで表す |
| 能力値 | 腕力・体力・器用さ・素早さ・知力・精神・愛・魅力。武器種ごとに参照する能力が違う | 同じ攻撃役でも、剣なら腕力、弓なら器用さ…と育て方が変わる |
| 属性・耐性 | 斬・殴・突・射＋熱・冷・雷・陽・陰。弱点で大ダメージ、耐性で軽減 | 編成・技選びの理由 |
| 陣形 | 並び順（ポジション）ごとに能力の補正が付く | 編成に「並べ方」という軸が増える |
| 防御・逃げる | コマンドとしての「防御」は無く、守りは技（かばう・構え）やアビリティで行う | 毎ターン必ず何かをする前向きな戦闘 |

## 2. この作品での対応

| RS | この作品 | 中身（数値） |
|---|---|---|
| ターン制 | ターン制に変更（旧来の CT＝行動時間は使わない） | 素早さ×(0.9〜1.1)×(1＋行動順アビリティ)。先制の技は先に、後発の技は最後に。素早い大ボスは 1 ターンに 2 回動く |
| BP | SP を廃止して BP に | 上限 20、初期 6、毎ターン +3、通常攻撃で +1（星盤の「通常攻撃時BP」で最大 +3）。エーテルは BP 全回復 |
| 威力ランク | E〜SSS | 倍率 E0.8 D1.05 C1.35 B1.65 A2.0 S2.5 SS3.2 SSS4.2（全体攻撃は ×0.62、連撃は回数で割って ×1.08）。消費 BP は D2 C3 B4 A6 S8 SS10 SSS12（全体 +2） |
| 連携 | 連携 | 2 連携 ×1.15、3 ×1.3、4 ×1.45、5 ×1.6（＋連携アビリティ・陣形）。敵の行動・攻撃でない行動・スタンで途切れる |
| OD | オーバードライブ | 攻撃 +2.5、連携 1 段ごとに +2.5、弱点 +1.5、被ダメ（最大HP比×12）。魅力・アビリティ・陣形で溜まりやすくなる。発動したターンは味方全員が先に動き、ダメージ ×1.2 |
| ひらめき | ひらめき | 各キャラ 1 つ。Lv20 以上で派生元の技を使うと 10%（ボスがいると 2 倍）で閃き、その場で閃いた技に変わる |
| 技の熟練 | 技Lv | 使用回数 3・8・15・25・40・60・85・115・150 で Lv2〜10。威力 +2%/Lv、Lv4・Lv8 で消費 BP -1 |
| 技のセット | 技・術セット（4 つ） | 覚えている技・術から 4 つ。キャラ詳細の「技・術」で付け外し・並べ替え。空きがあれば新しく覚えた技が自動で入る |
| アビリティ | パッシブスキル → アビリティ | 1 人 3 つ（Lv1・25・50 で解放）。段階 I〜V：Lv で +30 ごとに III まで、星盤・天星盤のノードで +1 ずつ。段階が上がるたびに効果が増え、数値も伸びる |
| 能力値 | 8 種を追加 | 下の 3 章 |
| 属性 | 斬・打・突・炎・氷・雷・風・地・光・闇（従来どおり） | 弱点 ×1.7、耐性 ×0.5（従来どおり） |
| 陣形 | 陣形（6 種） | 星環・天穹・城塞・疾風・連星・祝星。編成画面で選ぶ |
| 防御・逃げる | 廃止 | 守りは「挑発」「鉄壁の構え」「守りの祈り」など技と、アビリティ（被ダメ軽減・反撃・回避・こらえる）で |
| （RS に無いもの） | 星臨 | 下の 4 章。RS の「必殺技」のような切り札を、この作品の星臨として残した |

## 3. 能力値

| 能力値 | 効き方 |
|---|---|
| 腕力 | 剣・大剣・棍棒・体術・爪・大鎌の技の威力 |
| 体力 | 物理の被ダメージを減らす（＝旧「防御」） |
| 器用さ | 小剣・弓・剣の技の威力と、会心率（自分の 8 能力の平均との比で最大 +15%） |
| 素早さ | 行動順（＝旧「素早さ」×3 の目盛り）。体術・爪の威力にも |
| 知力 | 術の威力（＝旧「魔力」） |
| 精神 | 術の被ダメージを減らす（＝旧「精神」） |
| 愛 | 回復の技・術の回復量（×0.8〜1.6） |
| 魅力 | 追加効果（状態異常・弱体）の成功率（×0.8〜1.5）と OD の溜まりやすさ（×0.9〜1.25） |

武器種ごとの配分（技の威力）：剣＝腕力60%＋器用さ40%、大剣＝腕力80%＋体力20%、小剣・弓＝器用さ80%＋腕力20%、棍棒＝腕力90%＋体力10%、
大鎌＝腕力60%＋知力40%、体術＝腕力50%＋素早さ50%、爪＝腕力60%＋素早さ40%、杖＝腕力70%＋器用さ30%。

**バランスの取り方**：Lv1 の時点で、武器種の配分から計算した「技の威力」が旧来の「攻撃」と同じになるように、主能力（剣なら腕力）の初期値を自動で決める（`RSC.pf`）。
防御・精神・魔力・素早さは旧来と同じ値。以降は能力ごとの成長（S〜D）で少しずつ個性が出る。装備・星盤の「攻撃」「攻撃%」は従来どおり上乗せされる。

## 4. 星臨（特殊アビリティ＋奥義）

- 星臨ゲージが満タンで、行動を消費せずに発動（同時に 2 人まで）。**3 ターン**＋位階（Ⅱ・Ⅲで +1）＋星盤で続く。
- 発動中は**星臨アビリティ**で大きく強化され、いつもの技・術（セットした 4 つ）に加えて**奥義**を 1 度だけ使える（BP 0）。
- 旧来の「星臨中だけ技が入れ替わる」「ゲージ消費型」「行動が自動になる（ヴァルク）」は廃止。キャラごとの特色は星臨アビリティと奥義に移した。

| キャラ | 星臨アビリティ | 奥義 |
|---|---|---|
| リオ | 全能力+20%・与ダメ+20%・毎ターンBP+2・味方全体の与ダメ+10% | 星光終天斬（光・単体＋味方の攻撃/魔力↑） |
| ガルド | 被ダメ-45%・敵の攻撃を全て引き受け蓄積・毎ターンHP5%回復 | 城壁崩し（蓄積を敵全体へ） |
| ミレイユ | 術の与ダメ+40%・属性を切り替えると+20%・術の消費BP-2 | 絶対零度の太陽（無属性・全体＋精神↓） |
| シオン | 発動時に敵を遅らせる・必ず先に動く・追撃40%・回避20% | 影縫・千刃乱（風・6連撃＋スタン） |
| ノア | 聖域（倒れるダメージを1度HP1で耐える）・毎ターン味方HP10%回復・回復量+30% | 聖機の福音（全員復活＋回復＋被ダメ軽減） |
| エルナ | 攻撃が全て会心・弱点ダメ+30%・防御30%無視 | 天穿・神鳴（雷・全体＋スタン） |
| バルザ | ターンごとに攻撃+15%・炎ダメ+30%・被ダメ-20% | 溶鉄爆砕（炎・全体＋防御↓） |
| クロウ | 失ったHPで与ダメ上昇・闇攻撃で必ず毒・吸収10% | 死経（敵の今のHPの40%、ボスは12%） |
| ハクア | 連撃+2回・氷で25%スタン・連撃の与ダメ+20% | 氷華乱舞・終の型（タイミング入力で最大16連撃） |
| ジン | 攻撃・素早さ+30%・ポポの追撃60% | 獣王撃（弱点の属性に変化する一撃） |
| セレス | 発動の瞬間を記録・敵の素早さ-30%・味方全体のBP回復+1 | 巻き戻し（記録した瞬間まで味方のHPと戦闘不能を戻す） |
| ヴァルク | 与ダメ1.5倍・炎/闇の被ダメ-50%・吸収10% | 終焉竜咆（炎・全体） |

## 5. 技・術の整理

旧来は 1 人あたり初期 3＋Lv 2＋星盤 2＋天星盤 2＋ジョブ 2〜3 の約 10 種あった。これを **6 種＋ジョブ 1 種**に絞り、効果を統合して追加効果を増やした。

| 習得 | 例（リオ） |
|---|---|
| Lv1 | 光刃（光・単体 B・50%で防御↓）／斬り払い（斬・全体 C・30%で攻撃↓） |
| Lv10 | 鼓舞の灯（味方全体 HP15%回復＋攻撃・魔力↑）← 応急手当・希望の灯・鼓舞の灯を統合 |
| ひらめき（Lv20〜、光刃から） | 灯火連斬（光・3連撃 A・HP半分以下の敵に1.5倍・会心+20%） |
| 星盤 | 紫電一閃（雷・単体 S・先制・35%でスタン） |
| 天星盤（Lv60〜） | 天灯星斬（光・単体 SSS・防御↓・自分の攻撃↑）← 極技 2 種を統合 |

ジョブの技も各ジョブ 1 つ（烈風二段・護りの構え・癒しの光・看破の矢）に統合した。
リオ・ガルド・ミレイユの技は、ver0.36 の固有演出をそのまま使えるよう、技の id を引き継いでいる。

## 7. バランスの確認

`tools/smoke.js` に加え、同じ条件（Lv64・装備なし・位階Ⅱ・通常AUTO、黒炎竜ヴォルガノン Lv68）で新旧を 4 組×2 戦ずつ戦わせた。

| 版 | 結果 | ボスの残りHP（平均） |
|---|---|---|
| ver0.36（旧） | 全敗 | 約69% |
| ver0.37（新） | 全敗 | 約65% |

装備なしでは勝てない強さのまま、与えるダメージはほぼ同じ（連携・OD・奥義のぶん、少しだけ新しい方が強い）。
